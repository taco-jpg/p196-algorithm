# W03: finite-time regeneration of a decimal insertion defect

**COMPUTED, exact scope**: for every integer Q in 15..450, compare the *true decimal* reverse-and-add orbits of 12(99)^Q34 and 12(99)^(Q+1)34 through 80 steps after the first collision. Pair each LSD-first digit list into two-digit base-100 groups only AFTER performing the ordinary decimal operation. The longer grouped word initially equals the shorter grouped word with exactly one 99 inserted. Let F(Q) be the first step when this property fails. A healing at t>F(Q) means the exact insertion property holds again.

Every Q=15..450 has a recorded first collision. Precisely 17 Q have a postcollision healing state within 80 steps; 21 such states in total, maximum three consecutive healing states. All 17 examples (including Q=235: collision 772, regeneration 776,777,778, then failure 779) are listed in calculation/new_structures/agent-W03/repair_events.csv. In particular Q=52 collides at t=175, local group rewrite [88] -> [98,89]. The old singleton block evolves [88],[77],[55],[11] at t=175..178, matching a temporary doubling-modulo-9 motif but not a proved universal recurrence.

The C++ scanner performs genuine base-10 column additions, not symbolic template assumptions, and checks the *complete* grouped words. The independently written Python checker uses unbounded Python integers, genuine decimal string reversal, a different grouping implementation and exhaustive insertion-position search. It replays all states t=0..F(Q)+80 for each of the 17 healed Q and 24 seeded-random nonhealed controls, checking nonpalindromicity for these 41 adjacent pairs at every state. Mutation control inserts a false healing at the first collision and is rejected.

Reproduce: bash calculation/new_structures/agent-W03/reproduce.sh (C++17 and Python 3 only). The runner creates /tmp/w03_front_scan.csv, verifies every healing event and controls using the independent Python oracle.

**Interpretation:** the collision of two boundary-defect fronts does not necessarily annihilate their shared insertion language: it can re-enter that language exactly, even for three consecutive states. None of the 17 observed healing episodes survives all 80 subsequent states. A candidate next format is a phase-dependent regenerative 99 reservoir coupled to another band, not a stationary neutral centre. This is not an infinite-time certificate, a Lean proof, or a statement about 196. The finite 436-value scan is not an all-Q claim.
