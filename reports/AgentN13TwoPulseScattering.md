## Four explicit seeds and four actual orbits

The root is the first reachable period-8, period-20 decimal pair-coefficient lattice in `calculation/decimal_frontier/lattice_formats/p8_scc.txt`. Source files embed its 39 root coefficients and 20 cyclic coefficients, so all seeds are generated reproducibly with no repository external input. Let `P_j` be the (palindromic) paired-digit sum at least-significant-first index j. Each coefficient q is lifted to real decimal digits `(min(q,9),q-min(q,9))`, with reflected digit placement, yielding four positive initial integers, each 10400 decimal digits:

* A: base seed, with clean lattice path+cyclic bulk.
* B: perturb j in [1800,1849], replacing q by `(7*j+11)%19`; all other q unchanged.
* C: perturb j in [2600,2649], replacing q by `(3*j+7)%19`; all other q unchanged.
* D: apply both nonoverlapping perturbations simultaneously.

Run literal `N -> N+reverse(N)` on A/B/C/D, using independent decimal digit arrays in C++ and built-in arbitrarily large Python integers in the check. All four orbit lengths remain identical in the C++ full horizon, and the 88-phase seed exterior remains available at first eight positions. Define each time-dependent affected set of paired coefficients `S_B(t)={j:P_B,t(j)!=P_A,t(j)}` and `S_C(t)` analogously. Observe `P_D,t` (the orbit with **both** original patches).

## Exact finite nonlinear-scattering timeline

Three event types are computed from EVERY lower-half paired position at each time t=0..4000:

1. **Overlap event:** the first `S_B(t) ∩ S_C(t)` nonempty. This first occurs at **t=836**, with exactly one overlapped paired position. Earlier, the two single-pulse domains of influence are disjoint.
2. **Nonlinear contamination outside overlap:** at any j not in the intersection, compare `P_D,t(j)` to the uniquely determined value: `P_B,t(j)` if only B changed it, `P_C,t(j)` if only C changed it, and `P_A,t(j)` if neither changed it. The first mismatch occurs at **t=841**, with two such positions. In particular the independently propagated pulses have an observed five-step delay from first overlap before they alter even the exclusive or unaffected region.
3. **Newly affected position outside BOTH single-pulse sets:** find j with `P_B,t(j)=P_C,t(j)=P_A,t(j)` but `P_D,t(j)!=P_A,t(j)`. The first event is **t=858 at j=2415**, 22 steps after first overlap. This is a directly measured daughter disturbance generated by interacting pulses: neither isolated perturbation alone reaches that position at that time, whereas the combined perturbation does.

Because the nonlinear-contamination definition excludes positions where both single-pulse orbits already differ, this is deliberately a limited, unambiguous superposition statement. Before t=836, all four pairwords fit a uniquely defined pointwise merge **on all positions**. At t=836..840 the overlap is nonempty, so values there are not predicted by a single-pulse superposition, but the remainder still matches. At t=841 the first unambiguous outside-intersection mismatch appears. Thus no unjustified statement that the two orbits remain globally independent in their overlapping cells is made.

Beyond first emergence, the daughter set need not form a stable coherent glider: for example the count of positions outside the single-pulse union where D differs is 0 at t=900, 2 at t=1100, 6 at t=2000, 8 at t=3000, and 7 at t=4000. This is a nontrivial *creation mechanism* whose outgoing phase structure must be studied further, not a claim of a repeating source.
