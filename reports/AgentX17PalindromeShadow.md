## Exact seed and observed invariant

Let `u = 83271645`. For any odd `n`, define a decimal palindrome `P_n` by its least-significant-first digit list `a_i = u[min(i,n-1-i) mod 8]` for `0 <= i < n`. Set `Q_n = P_n + 10^(n/2-1)` with integer division; the specified digit is initially below 9, so this changes only one position one cell below the middle. The chosen instance is `n=10001`. The perturbed seed is **not** a palindrome; its baseline is.

Run `A_{t+1}=A_t+rev10(A_t)` from `P_n` and `B_{t+1}=B_t+rev10(B_t)` from `Q_n`. In all **20,001** states `t=0..20000`, both numbers have exactly the same decimal length. For each state, their decimal digit words agree in the **first and last at least 2,202 positions**. Equivalently, the symmetric pair-sum words `d_i+d_{L-1-i}` agree in those two exterior intervals. From `t=1` through `20000`, the baseline has a witnessed asymmetric digit pair **entirely within that common exterior**. At `t=0`, the perturbed one-cell seed is directly nonpalindromic. Thus all 20,001 perturbed words are demonstrably nonpalindromic, not merely nonpalindromic by a hash criterion.

Selected exact checkpoints `(t, length, matched exterior each end, first baseline witness position from LSD end)`: `(0,10001,4999,-1)`, `(10000,14136,3910,2)`, `(20000,18242,2202,2)`. The baseline's asymmetric witness can shift in the outer region; no fixed single digit position is asserted. All 20,001 **complete** baseline and perturbed decimal strings were matched between two independent engines: (i) ordinary digit-by-digit column arithmetic, (ii) GMP arbitrary-precision integers that convert to strings, reverse, and add. The independent program checks every full word, every outer witness and absence of palindromes, not merely stored checksums. The CSV records 211 checkpoint hashes for audit. Other scanned `n` values are in `length_scan.csv`; these are separate tested instances, not a statement about all odd `n`.

## Carry-sync theorem and a possible certificate format

Let `x,y` be canonical equal-length base-`b` digit words and `q_i=x_i+x_{L-1-i}`, `q'_i=y_i+y_{L-1-i}` in least-significant-first order. Suppose `q_i=q'_i` on a region. Normalization advances carry `c` by `f_q(c)=floor((q+c)/b)`, where `c in {0,1}`. **For every `q != b-1`, the outgoing carry is independent of incoming carry**; at `q=b-1` it simply transmits it. Thus an incoming mismatch of carries can cross a common region only through a run of pair-sum `b-1` columns, and the first other common column resynchronizes the carries. This proves an exact two-track *shadow boundary* rule for any base. In particular, if two sources agree outside a symmetric interior defect, their next output agrees at both exterior ends up to the first carry desynchronization, with the possible additional length-overflow mismatch checked separately. This is a direct induction on digit columns, not a finite-horizon extrapolation.

**Synchronized-shadow certificate format (sound conditional criterion):** use a finite phase-indexed family of *folded two-orbit regular languages* on the paired symbols `(x_i,x_{L-1-i},y_i,y_{L-1-i})`. Each accepts only (a) canonical equal-length word pairs with an interior defect, (b) exterior equality plus a certified nonpalindromic witness for `y`, and (c) specified allowed carry-boundary states. Verify exact inclusion of both reverse-and-add outputs, including the two overflow choices, from each phase language into its successor; require the final phase to return to the initial language and exhibit an initial accepted pair. Then induction proves the `y` orbit is forever nonpalindromic. The transition relation is regular in folded coordinates: one guesses both outgoing carry streams and checks each adjacent column's carry equation and both end-carries, including the one-cell reflection shift on overflow. A finite automata inclusion check therefore suffices for each edge. This is a **sound format, not an instantiated closed decimal certificate**, and it differs from a one-orbit regular-centre invariant by using a second evolving *palindrome anchor* and an explicit carry-resynchronization relation.

The current computed example **does not meet closure**. At step **32581**, the first exterior-witness guarantee fails in the continued digit-only run (although the perturbed word remains nonpalindromic in the inspected range); at **32608** the common exterior width reaches zero; and at **32615** the baseline and perturbation have unequal digit lengths. The 20,000-step horizon precedes all of these events. This redirects the search toward a replenishing carry-sync guard or a phase-locked shadow-boundary drift with nonnegative net exterior width, not toward declaring the finite transient an infinite proof.
