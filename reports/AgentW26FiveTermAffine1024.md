## Soundness format: canonical digit-affine repeat lemma
For base b>=2 and coefficients 0..2b-2, normalization scans a block w with incoming carry c in {0,1}; its outgoing carry f_w(c) is nondecreasing in c. Every nondecreasing function {0,1}->{0,1} is idempotent. Thus f_w(f_w(c))=f_w(c). For any q>=0, the exact normalized digit block for w^(q+1) is `first(w,c) ++ steady(w,f_w(c))^q`, and the outgoing carry is f_w(c), independent of q. Fixed literals and several synchronized repeats compose in order, and the final carry yields an optional extra high digit. The code checks the fixed-point equality separately for every repeated block; no sampling of q is used. This lemma can be formalized as a small Lean theorem over Bool carries and digit lists, independent of all N01's 80-state matrices.

Represent the resulting least-significant-first canonical digit word by pieces (w,a,c) meaning w^(a*q+c), with all counts nonnegative. Set X=10^q. If w has length m and low-to-high value v, its repeated numerical contribution (before position shift) equals `v*(10^(m*c)*X^(m*a)-1)/(10^m-1)`. Multiplying by the length-dependent 10-power of preceding pieces gives a Laurent/rational polynomial; in this instance all exponents are nonnegative. Word reversal reverses both piece order and each block. If successive state polynomials satisfy `F_(t+1)(X) = F_t(X)+Reverse(F_t)(X)` coefficientwise and their canonical first and last digits differ, every integer q>=0 produces exactly the specified nonpalindromic finite orbit. This is an exact induction on edges, not a finite-horizon sample extrapolation.
