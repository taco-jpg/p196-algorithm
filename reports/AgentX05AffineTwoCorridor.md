# Agent X05: independently pumped affine-RLE decimal corridors

**Label: COMPUTED.** The program certifies, without enumerating the integer parameters, **2,000 exact reverse-and-add steps and 2,000 nonpalindrome tests** for every decimal number in the family

`N(A,B) = val_10(P(A,B))`, with `P(A,B)` least-significant-first pair-coefficient word

`P(A,B) = 9^(A+1) 18^2 9^B 0^2 9^B 18^2 9^(A+1)`,

for **independently chosen** integers `A>=10000` and `B>=10000`. There is no assumed relation between A and B. The final symbolic word at step 2000 has 5,231 run terms and evaluates to 40,837 pair-coefficient positions at A=B=10000. This is **not** an infinite certificate and is not a result about 196. The output does **not** assert that the two bands remain neutral 9 forever: they may turn into absorbing 0 or 18 during the exact evolution.

**New format, exact interpretation (PAPER PROOF of the step-soundness invariant):** A symbolic word is a finite run list `(v_i, c_i+u_i A+v_i' B)` with coefficients in `0..2b-2`, together with a guard orthant `A>=A0,B>=B0`. Here `v_i'` is a length coefficient, not the symbol `v_i`. All stored lengths must be positive throughout the guard. Each run's normalization is computed with the exact integer carry: a run of coefficient `b-1` leaves carry unchanged and emits a constant digit; any other coefficient maps the carry to a constant after the first position, so the first digit and remainder form at most two constant-digit runs. Canonical leading zeros are stripped. To form the next pairword, zip the normalized digit runs from the two ends; every choice of shorter remaining run must be proved by a linear-inequality sign check **uniformly for all parameters in the guard**. If its sign is not forced, the engine stops rather than guessing. A zipped run with unequal digit symbols proves nonpalindromicity for every parameter. Thus each accepted symbolic step is an exact all-parameter reverse-and-add step, not sampling. The implementation uses only base integer operations and exact affine signs.

**Why this is a potential certificate format:** A finite graph of affine-RLE phases with affine counter updates `F_t` and guards `G_t` becomes an infinite certificate if (i) every edge's exact symbolic normalization/zip equals its stated target template, (ii) its digit-word zip has a forced mismatch on each edge, (iii) `F_t(G_t)` is included in `G_(t+1)` and all run lengths stay positive, and (iv) the graph is a finite directed cycle returning to its initial template. Induction along the cycle then proves no palindrome at any time. Unlike the synchronized diagonal two-band witness of N01, the two run-length parameters here are **unconstrained and independent**, and the engine also handles time-varying 0,9,18 or other coefficient runs without a preselected lattice clock. This new format is partial: when an affine length comparison depends on the sign of `A-B` or a run length might reach zero, the current checker cannot resolve it without partitioning the parameter guard into cones. It also does not automatically search for cycles or produce Lean proof objects.

**Controls:** `controls.py` compares the one-step symbolic arithmetic and palindromicity flag to an independent full-integer computation in 1,080 pseudorandom symmetric coefficient words across bases 3,7,9,10,13,16, and replays 300 ordinary base-9 steps from the existing verified lattice's known starting integer with no palindrome. `independent.py` performs 1,200 ordinary Python big-integer decimal reverse-and-add steps on `A=10000,B=10017`, comparing the *entire* canonical decimal digit string to the independently normalized expanded symbolic pairword at every time. All 1,200 pairword checks and nonpalindrome tests passed; final decimal length 40,537. A distinct earlier `A=2000,B=2017` 300-step replay also passed, but this smaller pair is not within the global 2000-step guard. These replay checks do not by themselves prove the universal statement; its justification is the exact arithmetic/inequality checker above.

**Reproduction:** from repository root run `bash calculation/new_structures/agent-X05/reproduce.sh`; regenerate the complete per-step numeric data via `python3 calculation/new_structures/agent-X05/affine_rle.py --min 10000 --steps 2000 --checks 0 --period 0 --save /tmp/x05_full.json`.
