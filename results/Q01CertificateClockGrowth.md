# Q01CertificateClockGrowth

**PAPER PROOF**: a literal fixed-centre paired periodic-exterior return of primitive temporal period p, overflow count S per period and spatial word length m needs k=p*r, r*S=2*m*g, g>=1. Hence (k,g)=a*(p*2*m/gcd(S,2*m), S/gcd(S,2*m)), a>=1. Merged band: replace 2m by m.

**PAPER PROOF**: any same-cap paired return uniform for every sufficiently large q obeys 2*(2^k-1)*sum(W)==0 and 2*g*sum(W)==(2^k-1)*(2*sum(B)+sum(C)) modulo 9.

**Scope:** necessary conditions only for literal rooted phase returns, not phase-twisted/moving-centre/multiband formats; no decimal instance, all-time seed, Lean proof, or sufficient carry/centre repair. The p12/m9 fixed-centre k>=216 specialization is already AgentY18's theorem, not new.
