# U47 target: cyclotomic carry-cocycle for rooted decimal T*

Prove or refute the fixed-seam endpoint obligation for the rooted p12/m9 family
`T(q,k;J,U,C) = (B W^q J U^k) C reverse(B W^q J U^k)`, with `|W|=9`,
`|U|=3`, and the physical 120-step overflow word `(1000)^30`.

Current subgoal: derive an exact carry-only necessary condition for every genuine
120-step endpoint `T(q,k) -> T(q,k+5)`, then use it to constrain a self-reproducing
seam. The subgoal is not itself a return certificate or a proof that a decimal
Lychrel number exists.
