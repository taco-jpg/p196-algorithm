# Y22 target

Decide whether a rooted decimal p12/m9 family
`B34 | W9^q | J | V_k | C | reverse(V_k) | reverse(J) | reverse(W9)^q | reverse(B34)`
can have an exact 120-ordinary-step, 30-overflow return to the same fixed finite collar and the literal-prefix extension `V_k -> V_(k+5)`, where `V_k` codes the first `k` letters of the regular paper-folding word by `A=(9,0,18)` and `B=(9,2,16)`.

Target theorem: no such fixed-collar literal-prefix return exists for all sufficiently large `k` under the rooted clock `gamma=(1000)^30`. This does not exclude moving/growing collars, phase-changing centres, or other clocks.
