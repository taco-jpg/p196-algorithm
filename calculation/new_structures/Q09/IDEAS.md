# Q09 negative constraints, only scope-noted
- Reversal is not an orbit-commuting involution: F(rev(n))=F(n) on unit-nonzero numbers, not rev(F(n)).
- Digit relabeling with pi(0)=0 commutes only when pi=id; even composing with reversal gives no global commutant.
- Ordinary decimal shifts n->10^k*n (k>0) and n->n+c (c!=0) are not global orbit symmetries.
- Nine's complement is a genuine CARRY-FLIPPED *local* automorphism, not a rooted reverse-add automorphism: physical input carry0 breaks it.
- Fiberwise mirrored-digit swaps are valid only for one step and already represented by pair-coefficient words.
- No candidate for periodic complementary carry-inverter regeneration or positive-growth base-10 certificate is currently known here. Do not present the symmetry classification as a solution of the all-time existence problem.
