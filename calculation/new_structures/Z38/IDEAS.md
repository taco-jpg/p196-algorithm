# Z38 IDEAS

- PAPER PROOF, exact scope: For the rooted phase-0 p12/m9 clock, the overflow word has 30 ones per 120 steps. If q and the centre C are unchanged and both seam widths lie in [3,5], then a template with a repeated motif of length r has total coefficient length 2(|B|+9q+|J|+rk)+|C|, so a 120-step return forces Δ|J|+rΔk=15. For U4 (r=4), the only allowed solution is Δ|J|=-1, Δk=4; hence every 120-step edge shrinks the seam, so no indefinitely closed family exists in this fixed-q/fixed-C width slice. For alternating mixed-U (r=6), no Δ|J| in [-2,2] satisfies the equation, so no 120-step return exists in this slice. At 240 steps the corresponding equation is Δ|J|+rΔk=30: mixed-U forces Δ|J|=0, Δk=5; U4 forces Δ|J|=+2, Δk=7 or Δ|J|=-2, Δk=8. This is a length-only obstruction, not a carry check, candidate, or decimal Lychrel certificate; it redirects search toward 240-step mixed-U returns and 480-step U4 seam-width cycles.
