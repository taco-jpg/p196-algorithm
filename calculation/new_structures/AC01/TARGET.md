# Exact target (AC01)

Find or exclude, **for a specified finite centre length n**, a palindromic coefficient word C with digits in 0..18 and even midpoint if n odd, such that rooted p12/m9 phase-0 T*(q,k;J=[5],U,C), at q=14,k=100, after 120 genuine decimal additions has pair coefficients on the centre ±(122+n+30) agreeing with the same C and with U^(k+5) flanks; additionally validate both carry boundaries and actual overflow clock.

This is a **necessary** local predicate, not the full epoch return; a successful centre still needs an intact W9, identical J, all-width lifting, and guarded intermediate phases. Distinguish endpoint-only from strict W9 at every intermediate step. The all-time certificate remains UNDECIDED.
