# The exact universal quotient that forgets carries

This is a structural no-go theorem for one algebraic approach to decimal
Lychrel existence. It does **not** prove decimal Lychrel existence, the
196 conjecture, or persistence of a nonzero carry obstruction. It is not a
claim that every possible algebraic or nonlinear invariant is impossible.

The main result goes beyond the existing quadratic-coordinate formulas:
the ideal generated by **all actual carry corrections**, with both length
branches included, can be computed exactly. Its quotient retains only
elementary modular data, and explicit palindrome-producing targets realize
every retained class. Any successful refinement must retain some carry
information or use a different hypothesis about the particular orbit.

## Definitions and the exact ideal

Use least-significant-first coefficients. Let q be a canonical reciprocal
word of length L, with entries in {0,...,18}, q_0>0, and an even central
entry when L is odd. These are exactly the mirrored digit-sum words of
positive decimal integers. Put

    Q(x) = sum q_i x^i,
    C(x) = sum c_i x^i,
    C*(x) = x^(L-1) C(1/x),
    h = c_(L-1),

where c_i is the carry leaving column i in normalization of q, and the
incoming carry at column zero is zero. Let Q_new be the mirrored digit-sum
polynomial of the normalized output. Work in S=Z[x,x^-1]. The existing
normalization identities give the carry defect

    Delta_0 = Q_new - 2Q
            = (x-10)C + (x^-1-10)C*,                 if h=0;

    Delta_1 = Q_new - (1+x)Q
            = (x-10)C + (1-10x)C*,                  if h=1.

Define

    p = x^2 - 20x + 1,
    g = 9(x+1),
    I = (p,g) in S.

**Theorem 1.** The ideal generated by the carry defects of all canonical
words is exactly I. The same ideal is generated if only actual
nonpalindromic integer inputs are admitted.

**Proof, inclusion.** C(1)=C*(1), so there is an integer polynomial
T=(C-C*)/(x-1). Use

    (x-10)(x-1) = p+g.

Direct substitution gives the following explicit ideal certificates:

    Delta_0 = p(C*/x + T) + gT;
    Delta_1 = pT + g(T-C*).

In the first branch h=0 makes C*(0)=0, so C*/x is even an ordinary
polynomial. Thus every actual defect belongs to I, with no assumptions
about symmetric carries or absence of neutral-nine runs.

**Proof, reverse inclusion.** Three valid nonpalindromic inputs suffice:

| Input n | q | Carry C | h | Defect |
|---|---|---|---|---|
| 150 | (1,10,1) | x | 0 | p |
| 109 | (10,0,10) | 1+x^2 | 1 | -g(1+x^2) |
| 159 | (10,10,10) | 1+x+x^2 | 1 | -g(1+x+x^2) |

The difference of the last two defects is -xg. Since x is a unit in S,
the actual defects generate both p and g. This proves equality. These
witnesses concern unrestricted valid inputs; no claim is made that they
occur on the 196 orbit.

The word “universal” has a precise scope: for any commutative ring R and
any ring homomorphism phi:S->R, phi removes every actual carry defect if
and only if phi factors through S/I. The theorem does not classify
carry-dependent maps, nonlinear maps, or special-orbit relations.

## The quotient and what it retains

**Theorem 2.** There is a ring isomorphism

    S/I  ~=  (Z/9)[epsilon]/(epsilon^2)  x  Z/22,
    x    |-> (1+epsilon, -1).

Consequently the quotient has exactly 9^2*22=1782 elements.

**Proof.** Since p=(x+1)(x-21)+22,

    9p - (x-21)g = 198.

Thus 198 vanishes in S/I. Apply the Chinese remainder decomposition
198=9*22. Modulo 9, g vanishes and p=(x-1)^2. Modulo 22, 9 is a unit,
so g forces x=-1 and p then vanishes. In the first factor x=1+epsilon
is a unit with inverse 1-epsilon; in the second x=-1 is a unit. This
also verifies that using Laurent polynomials introduces no extra cases.

The class of an ordinary polynomial Q is precisely

    (Q(1) mod 9, Q_derivative(1) mod 9, Q(-1) mod 22).

For a reciprocal polynomial of degree L-1,

    2 Q_derivative(1) = (L-1)Q(1).

Since 2 is invertible modulo 9, the derivative component adds no
information once the length is known. Canonical mirrored digit-sum words
also have even Q(1). If L is even, Q(-1)=0 identically. If L is odd,
Q(-1) is even. Thus at a fixed length the possible classes can be labeled
by

    s = Q(1)/2 mod 9;
    r = Q(-1)/2 mod 11 for odd L, or r=0 for even L.

For an input n, s is its digit sum modulo 9. For odd L, r is n modulo 11.
This is why the large-looking spectral quotient contains only familiar
modular information when restricted to physical q words.

The quotient dynamics is exact in all four parity/overflow cases:

    [Q_new] = 2[Q]       if h=0;
    [Q_new] = (1+x)[Q]   if h=1.

In the three displayed coordinates, (u,v,w) goes to

    (2u, 2v,   2w)       if h=0;
    (2u, 2v+u, 0)        if h=1,

with the appropriate moduli 9,9,22. In particular, the first overflow
kills the entire alternating-sum component, and it remains zero. This
is a statement about Q, not a claim that an even-length input n is
already divisible by 11. The latter need not hold.

## Every retained class has a palindrome-producing representative

**Theorem 3.** At every odd length L>=5, all 99 allowed pairs (s,r)
are realized by canonical carry-free q words. At every even length
L>=2, all nine allowed classes are realized by such words.

The normalized output from each such word is a palindrome, since all
entries are at most 9 and q is reciprocal.

**Odd-length construction.** Choose 1<=u<=10 and 0<=b<=9, set
a=min(u,9) and c=u-a, and take

    Q = a(1+x^(L-1)) + b(x+x^(L-2)) + c(x^2+x^(L-3)).

For L=5 the final two monomials coincide and give the even central
coefficient 2c. In every case all coefficients lie in {0,...,9}, the
leading coefficient is positive, and

    s = u+b mod 9,
    r = u-b mod 11.

These 100 pairs (u,b) cover all 99 residue pairs. To see this without
relying on a computer, suppose two pairs agree in both residues. Their
differences du,db lie in [-9,9] and satisfy

    du+db = 9k,   du-db = 11l.

Here |k|<=2, |l|<=1, and k,l have the same parity. If l=0, the only
possibilities are (du,db)=(0,0),(9,9),(-9,-9). If |l|=1, the permissible
odd k force either |du|=10 or |db|=10, outside the bounds. Therefore the
only duplicate is (u,b)=(1,0) versus (10,9). There are exactly 99 classes,
as required.

**Even-length construction.** Take Q=a(1+x^(L-1)), with 1<=a<=9.
Then s=a mod 9 and r=0, covering all nine possibilities.

These q words are realized by genuine nonpalindromic integer inputs:
split each symmetric pair of coefficients into digits, choosing the
leading input digit q_0 and the final input digit zero; split the central
coefficient evenly when present. The leading input digit is nonzero and
the input ends in zero, so the input itself is not a palindrome.

There is also saturation with the overflow branch retained. After the
first overflow, r=0. At every even L>=18 and odd L>=19, choose k in
{1,...,9}, put 11 in exactly k symmetric pairs including the outer pair,
and put zero elsewhere, including the central coefficient if present.
Then h=1, the normalized output is a palindrome by the exact {0,11}
criterion, and

    s=11k mod 9,  r=0.

These k cover every s. Their digit realizations can again be chosen
nonpalindromic, using leading digit 9 and final digit 2 for the outer
pair. Directly, their carry polynomial is C=Q/11 and their output digit
polynomial is E=Q+(x-10)C=(1+x)C, which is reciprocal; this independently
proves the asserted output palindromicity. Hence after the quotient's
alternating component has died, even
adding the current overflow flag cannot separate a retained residue
from all palindrome-producing targets at sufficiently large lengths.

## Consequence, boundary of the result, and remaining obligation

A predicate depending only on length and the universal carry-blind class
cannot certify next-output nonpalindromicity at the lengths in Theorem 3:
each class contains a counterexample. After the first overflow and at
lengths at least 19, this remains true even if the current overflow flag
is included. This excludes the natural route “kill every carry correction
in an algebraic quotient, then avoid the palindrome target by residue.”

It does not exclude a class plus a substantial digit-pattern restriction,
an invariant that follows the carry charge J, nonlinear information not
factoring through this quotient, or an orbit-specific theorem. Those
approaches have not been ruled out here.

The strongest remaining obligation for the original spectral approach is
still an actual-orbit renewal or persistence theorem: prove that a
nonzero carry-sensitive obstruction excludes every future palindrome
target, with no-overflow, overflow, both length parities, and neutral-nine
runs all included. The quotient classification explains exactly why
discarding those carry terms cannot discharge that obligation.

## Reproducible controls

Run `python astra_spectral_carry_quotient.py`. The standalone script checks
the explicit polynomial ideal certificates on all 75,447 canonical q
words of lengths 1 through 7, and 10,000 seeded random words of lengths
2 through 199. It checks all four parity/overflow cases, the three actual
input witnesses, the 198 identity, quotient size, and the explicit target
families. No floating point, external library, assumed trajectory
persistence, or probabilistic argument is used. The proof above is
unbounded; these finite checks verify the independent implementation.

The code and report do not modify canonical Lean files. The algebraic
theorems have not been formalized in Lean in this checkpoint.
