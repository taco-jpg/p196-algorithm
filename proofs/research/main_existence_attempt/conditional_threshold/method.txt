Conditional integer carry-history thresholds: exact method and scope
==================================================================

Goal: F(q)>0 implies F(Gq)>0, with F(q)<=0 whenever Gq is a palindrome
predecessor. Here F(q)=b+sum of fixed integer weights on the1123 tiles of
the unique exact addition-history path q->Gq. A positive finite q would
therefore give a decimal Lychrel witness after shifting its realization
by two reverse-and-add steps. No such certificate has been found.

Integer boundary and offset
---------------------------
For integer weights and integer b, F>0 is exactly F>=1; F<=0 includes
the zero boundary. A constant offset can be absorbed by adding b to
each terminal-tile weight because EVERY accepted history has exactly
one terminal tile. Searches retain a separate b: weights in[-B,B] and
b in[-O,O] is their explicit scope, not an independent bound on the
already shifted terminal weights. No gauge normalization is imposed.

Exact all-length safety
-----------------------
The archived48-state safety graph recognizes histories whose output
Gq is bad. Edge costs are minus the score weights. Potentials satisfy
p(initial)=0, p(v)<=p(u)-w(edge), p(u)-w(terminal)-b>=0.
These inequalities telescope to F(q)<=0 on every accepted safety path.
Conversely shortest-path distances give such potentials whenever all
safety paths have F<=0. Every state is reachable and coaccessible.
For edge weights bounded by B, shortest simple paths have at most47
edges; the implemented potential bounds[-48B,48B] lose no valid score.

Exact all-length conditional closure
------------------------------------
Use the trimmed two-history product:1258 states,24041 pair edges,3521
terminals. Each edge has the TWO separate integer scores(previous,next).
Its terminal consumes the extra next-history pair created by an odd
overflow when necessary. Add a source, sink, and source edges(b,b).
Then a violating history is exactly an accepted path with total first
score>=1 and total second score<=0.

Represent a path by nonnegative integer edge multiplicities, with unit
source/sink flow balance. Require the positive-flow support to be weakly
connected to the source. The directed Euler-trail theorem makes these
conditions equivalent to an accepted finite walk, including repeated
cycles and arbitrarily large multiplicities. Detached cycles may NOT
contribute scores. Hierholzer reconstruction, graph-edge continuity,
and direct qstep/history rescoring verify every returned SAT witness.

The checker adds connectivity lazily. If S is a detached component of
a candidate support, add:
   any positive-flow edge incident to S implies some positive-flow edge
   crossing S in either direction.
Every connected accepted walk satisfies this cut. UNSAT after any set
of these necessary cuts proves absence at every length. A connected SAT
flow is a real witness. UNKNOWN has no absence implication. There are
finitely many vertex subsets, so with terminating QF_LIA calls this is
a complete finite decision procedure; no length cutoff is required.

Exact score bisimulation
------------------------
Before solving, distinguish source, sink, and interior vertices. Refine
partitions until vertices in a block have the same SET of outgoing
(first score,second score,target block) triples. Accepted score-label
languages are preserved. Each quotient trail is explicitly lifted from
the actual original source by matching its next label and target block;
the defining bisimulation equality guarantees a matching original edge.
The final original word is independently rescored. Control graphs fell
from1260 states to56 states with this exact reduction.

A bounded HiGHS MILP front end finds counterexamples quickly. Every
returned flow is rechecked using exact integer arithmetic and lifted.
Its bounds, floating results, failures, and infeasibility are NEVER used
to prove absence. The unbounded exact QF_LIA checker remains the proof
route for UNSAT. All final controls, including an explicitly lifted SAT
counterexample, passed in checker_benchmarks_final.log.

Finite complete synthesis subfamily
----------------------------------
With finitely bounded integer weights and offset there are finitely many
scores. Exact nonemptiness is encoded on the46-state history graph using
connected integer flows. For weights in{-1,0,1}, products weight*count
are exact finite If-cases and remain QF_LIA, with counts unbounded.
Each candidate is checked on actual words and then by the all-length
checker. A counterexample adds the necessary clause F(q)<=0 or F(Gq)>=1.
An observed future bad-output state instead justifies F(q)<=0 by finite
induction. Each clause removes the current score; an ideal terminating
checker thus gives complete CEGIS over this finite weight/offset box.
Actual timeouts are only UNKNOWN. Positive cycles are pumped exactly to
extract a manageable finite seed independently of the solver's flow size.

Unbounded rational discovery is a separate search. Rational models are
scaled to integer weights before all-length checking. Finite UNSAT in
the homogeneous real synthesis also blocks a genuine real-valued
threshold invariant for that seed: any true invariant can be positively
rescaled so all finitely many required positive scores are at least1.
The archived fixed-seed UNSATs currently rely on Z3; SMT-LIB and the
actual finite closure words are retained for audit, with no independently
replayed proof certificate claimed.
