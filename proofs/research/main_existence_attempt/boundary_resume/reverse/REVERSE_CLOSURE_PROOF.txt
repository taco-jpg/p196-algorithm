EXACT REVERSE VIABILITY CERTIFICATE FOR THE 24-PHASE 936 EXTERIOR
14 October 2026

Scope and current status
------------------------
The supplied finite certificate concerns only the archived spatial column
graph for the N,O alternating 24-phase, fixed-width 8/17 exterior, with a
periodic tail equal to a permutation of (9,3,6) or (9,12,15).
It is not a nonexistence theorem for decimal Lychrel numbers, for 196, for
other clocks, or for longer temporal periods. It supplies no finite seed.
The computation has not been formalized in Lean. The stronger arbitrary-
temporal-period certificate in SOFIC_ALL_PERIOD_PROOF.txt supersedes the
period restriction of this first certificate.

The generator reverse_viable.cpp reaches exact reverse closure after five
new-state layers. The certificate viable_closed_states.txt contains 39,194
C12 temporal-rotation representatives. It contains the target states up
to rotation and does not contain the exterior root. Every predecessor of
a certificate state either has no predecessor at all, or is again in the
certificate up to rotation. The root is checked explicitly before any
predecessor pruning. The independent standard-library checker
check_reverse_certificate.py has replayed all these properties successfully;
see independent_check.json. The search log alone is not the certificate.

Exact graph and inverse fibers
------------------------------
The temporal pair index j belongs to Z/12Z. Write the new (inner) cut's
slot as (alpha_j,beta_j,delta_j,zeta_j), where the first three entries
are bits and zeta_j belongs to {-1,0,...,9}. A prior (outer) cut slot is
(a_j,b_j,c_j,z_j). A column has N/O coefficients Q_j,R_j in 0..18, and
O high outgoing carry e_j in {0,1}.

For each new slot, enumerate local options

  x_j=(Q_j,a_j,b_j,c_j,e_j,R_j)

satisfying exactly:

  R_j = zeta_j + 10 e_j,
  R_j in 0..18,
  R_j<9 implies e_j=0; R_j>9 implies e_j=1,
  floor((Q_j+a_j)/10) = alpha_j,
  (Q_j+a_j) mod10 + (Q_j+delta_j) mod10 = R_j,
  floor((R_j+b_j)/10) = beta_j,
  c_j = floor((Q_j+delta_j)/10).

Enumerate Q_j in 0..18 and a_j,b_j,e_j in {0,1}; hence this is an
exhaustive, finite inverse fiber. Across all 88 possible new slots,
78 fibers have size two, 8 have size one, and 2 are empty. The empty
slots are (0,0,1,0) and (1,1,0,8).

For adjacent chosen options x_j and x_(j+1), define

  z_j = Q_(j+1) - ((R_j+b_j) mod10) - e_j.

The adjacency is allowed exactly when

  -1 <= z_j <= 9,
  z_j=-1 implies e_j=1,
  z_j=9 implies e_j=0.

For every allowed cyclic option path x_0,...,x_11,x_0, take the prior
state with slots (a_j,b_j,c_j,z_j). These and only these are predecessors.

Proof of inverse completeness
-----------------------------
An actual forward edge obeys the archived equations. Its new zeta_j is
R_j-10e_j, its new low carries are alpha_j and beta_j, and its new N high
carry is delta_j. Therefore its Q,a,b,c,e,R occur among the local options.
Its temporal N coefficient Q_(j+1) obeys the O equation, which rearranges
to the displayed formula for z_j. The old z/carry constraint gives exactly
the displayed adjacency conditions. It is consequently enumerated.

Conversely, local options give all N equations, updated low carries, and
updated zeta. Each adjacency gives the O equation and old z/carry bounds.
Cyclic adjacency supplies the last temporal equation as well. Thus every
enumerated predecessor, with its recorded Q/R column, is a genuine edge.
This proof is independent of the exterior width.

The exact viability test
------------------------
A state has a predecessor iff its twelve local option sets admit an
allowed cyclic path. Each set has at most two members, so the checker
uses Boolean transfer matrices M_j (of size at most 2 by 2), with entry
(u,v)=1 precisely when option u at j is compatible with option v at j+1.
A predecessor exists iff the Boolean product M_0...M_11 has a nonzero
diagonal entry. Equivalently, choose each possible option at slot zero,
propagate its reachable option mask through slots one through eleven,
and test the closing adjacency. Both formulations are exact, with no
sampling, depth bound, or search cap.

Why no-predecessor pruning is sound
----------------------------------
Let r be the initial cut immediately after the mandatory first 8/17
column, and suppose there were a finite path

  r = s_0 -> s_1 -> ... -> s_k = target.

Every s_i with i>0 has a predecessor, namely s_(i-1). Reverse traversal
therefore never discards an intermediate state of this path. If it reaches
s_0=r it checks for the root before pruning. Consequently reverse closure
under predecessors which have any predecessor, together with an explicit
root check on every enumerated edge, is complete for reachability from r.

A convenient finite certificate formulation is: let C contain all target
states and their temporal rotations, exclude r, and require that for every
s in C and every p->s, either p is in C or p has no predecessor, with r
excluded even in the latter alternative. Backwards induction along the
hypothetical path contradicts r not in C. The certificate here stores C
up to the rotation action rather than listing all rotated copies.

Rotation and target coverage
----------------------------
Rotate the twelve temporal slots of all four arrays together. The option
and adjacency equations are uniform in j, so this is an automorphism.
The exterior root is fixed. Canonicalizing a state therefore preserves
the reverse closure condition and root exclusion.

Independently applying nearest-non-nine periodic carries for all twelve
permutations gives twelve distinct target cut states in exactly two C12
orbits. Both orbits occur among the input targets.txt states. Thus the
certificate includes every stated bulk target, not merely one chirality.

Packing
-------
A row of viable_closed_states.txt contains unsigned integers f,z.
The bits 0..11 of f are a, bits 12..23 are b, and bits 24..35 are c.
The j-th four-bit nibble of z stores the actual z_j plus one.
The first line is the number of canonical representatives.
