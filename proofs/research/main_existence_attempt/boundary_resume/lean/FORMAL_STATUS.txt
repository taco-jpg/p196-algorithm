LEAN 4.19.0 FORMAL STATUS — 14 OCTOBER 2026

What is proved
---------------
The concrete finite sofic certificate has been instantiated in Lean, not
merely left as a conditional invariant theorem. Eight exhaustive local
rank/projection checks establish a backward-closed union of cyclic-word
languages. Eight strict-rank checks exclude the uniform exterior letter 41.

BoundaryCertificate.no_finite_exterior excludes every finite path of inverse
columns from the uniform root to either primitive target-cycle language,
simultaneously for every temporal period. Width is the unrestricted number
of edges in ReverseClosure.Path; it is not a bounded search parameter.

BoundaryCertificate.options_complete proves that every bounded tuple
(Q,a,b,c,e,R) satisfying the displayed decimal inverse-fiber equations is
represented among the 164 stored local options. Completeness is over all
admissible arithmetic tuples, not only over the stored options. The proof
reduces arbitrary tuples to 13,376 possibilities for (letter,Q,a,b,e); the
equations determine c and R. The finite check is replayed in Lean.

BoundaryCertificate.no_arithmetic_exterior therefore states the exclusion
for ArithmeticColumn, which uses the explicit bounded decimal arithmetic
equations directly rather than option indices.

BoundaryCertificate.no_936_or_9_12_15_exterior covers all twelve permutations
of (9,3,6) and (9,12,15), every finite spatial width, and every positive
multiple of six temporal pairs. The twelve bulk inputs are replayed through
all 24 alternating N/O phases; their cut words are checked against all six
rotations of the two primitive six-slot words.

BoundaryCertificate.no_24_phase_936_or_9_12_15_exterior is the precise
12-temporal-pair/24-phase corollary for all twelve bulk inputs.

Scope limits
------------
This is an obstruction for the fixed 8/17 alternating exterior ansatz.
It is not a proof or disproof of decimal Lychrel existence or the 196
conjecture. It supplies no finite seed and excludes no other exterior clock.

The correspondence from these inverse-column arithmetic equations to every
ordinary decimal reverse-and-add orbit has a written argument in the
surrounding research report; that global correspondence is NOT formalized
in these modules. The formal endpoint is the explicit ArithmeticColumn
relation and the concretely derived periodic bulk words. The elementary
encoding of the exterior root (a,b,c,z)=(0,1,1,7) as 41 is also checked.

Trust boundary
--------------
The generic proofs in ReverseClosure.lean and SoficProof.lean are checked
by Lean's proof kernel and use no computational oracle. ReverseClosure's
two main pruning theorems print an empty axiom list. The sofic soundness
theorems use only propext and Quot.sound.

The finite data checks use native_decide in Lean 4.19.0. This invokes Lean's
standard Lean.ofReduceBool axiom and trusts the evaluator/compiler/runtime
for those Boolean computations. It is NOT kernel-only normalization of
the complete certificate. The arithmetic bridge additionally uses ordinary
Classical.choice to select a stored representative of an admissible option.
The final theorem's exact axiom list is:
  [propext, Classical.choice, Lean.ofReduceBool, Quot.sound]

There are no declared user axioms and no admitted proofs. Python is only a
data-transcription utility; its output is rechecked by the Lean checker.
No C++, Python result, JSON success flag, SCC computation, external process
exit code, or hash is used as a logical assumption by any Lean theorem.

Reproduction
------------
Run from this directory with any working Lean 4.19.0 executable:
  python compile_all.py /path/to/lean

The compilation order is:
  ReverseClosure.lean
  SoficProof.lean
  BoundaryData.lean
  BoundaryCertificate.lean
  ArithmeticBridge.lean
  BulkTargets.lean
  BulkDerivation.lean

compile_all.log records the compiler version, every exit code, and printed
axiom dependencies. The .olean files are disposable outputs, not evidence
that replaces replaying the source.

emit_certificate.py transcribes BoundaryData.lean from the two checked JSON
files in ../reverse. The rank-certificate SHA256 is:
22ed79d848ec883fdd0d39dedb73c0f4665637addc18b673975381d78f04d493
BoundaryData.lean contains all data needed to compile; the JSON files and
transcription script are not needed at proof-checking time.
