# 原始开发与重复发现记录

本目录逐字保存本轮工作区中的原始研究脚本、参数清单、输出和早期证书。文件名与内容不作事后修正。最终接受的五项结果以父目录的证明、生成器、核验器和证书为准。

`p196_continuation/` 内的 33 与 77 证书是补读原仓库之前的独立重建。后来确认相应结论已存在于四列和六列报告，因此它们是历史复核材料，**不计作本次新增成果**。`find_33.py`、`study_33.py` 和 `sharp_first_33.py` 属于同一阶段。

`graph4_rank.json` 和 `graph5_rank.json` 保留完整早期图结果；它们不是七列全图的穷尽证书。`prefix_graph_forward.py`、`prefix_inverse_fast.py` 和其他前驱脚本保存模型形成过程。`prefix_original.py`、`inverse_original.py` 源自对已归档论证的提取与重建，引用基线见父目录证明第 1 节。

`extend_prefixes.cpp` 是历史探索版本；父目录同名文件是有 3–7 列宽度检查的最终版本。早期代码和生成器可能依赖原始工作目录结构，并可能改写输出，应只在隔离副本中研究；日常复现使用父目录的独立生成器与核验器。

参数清单的长度不代表搜索已完成。关于各个 `seven_column_*.jsonl` 的实际完成范围、CAP 和中断，参见[最终探索说明](../exploration/README.md)。相同日志在这里与父目录中各保留一份，是原始布局和最终交付布局的逐字快照，不代表两个独立实验。

没有重建当时未保存的终端输出，也没有将未完成的搜索改写为排除结论。
