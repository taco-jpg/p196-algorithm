# Cap-three outer-map kernel certification

This package upgrades a previously published finite Python result to a Lean 4.19.0 kernel proof. It does not introduce a new cap-three discovery or claim a decimal Lychrel orbit.

The unchanged map and validity predicate are imported from Agent 7's `OuterFinite` and `OuterBounds`, as retained in `../../agent-109/outer-projection-bridge/agent7-deps/`. All eight even phases 2,4,...,16 and all base-19 words of length at most three are covered. There are 7,240 encoded words and 57 complete nonoverlapping batches, each covering all eight phases. Invalid words are rejected by the original `validOuter` premise.

`Cap3Encoding.lean`’s `decode_complete` proves unencoded coverage by explicit base-19 witnesses for each length. `Cap3Finite.lean`’s `cap3_exits_by_nine` combines every finite batch. `Cap3Bounds.lean`’s `cap3_exit_witness` states that every valid word in this domain exceeds length three at some time at most nine. The cap-parameterized `staysWithin` uses the inclusive times 0 through n convention. Generic conversion from the boolean false result to an actual iterate witness is proved by induction.

The previously known sharp witness is `(c,B)=(8,[11,9])`: it stays within the cap through time eight and becomes `(10,[4,9,6,6])` at time nine. `cap3_sharp_first_exit` gives this claim as a quantified proposition.

Finite proof source is generated by `python3 generate_batches.py`. All generated proofs use `decide +kernel`; there are no trusted lookup-table axioms or native evaluator calls. The generator is reproducible infrastructure, and running it does not itself verify the mathematical claims. The parent package's fresh dependency-closure runner provides the accepted compilation and transitive axiom evidence.

Original historical Python evidence: `proofs/contributions/2026-10-15-agent3-complementary-bulk/evidence/scan-L3.json`. The universal outer-map result remains separate from the actual whole-word projection and any proposed invariant or infinite orbit.
