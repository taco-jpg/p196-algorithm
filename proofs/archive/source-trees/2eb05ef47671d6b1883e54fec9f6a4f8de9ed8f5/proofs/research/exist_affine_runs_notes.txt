AFFINE RUN FAMILIES: AN EXACT POSITIVE-CERTIFICATE SEARCH

No decimal existence certificate was found.

A run family has a fixed list of coefficient values q_i and run lengths
alpha_i*k+beta_i, for every integer k>=0. The full q word is symmetric;
coefficients lie between0 and18, the outer coefficient is positive, and
an odd middle coefficient is allowed only if its central run always has
even length. Thus every family member represents mirrored digit sums of
a genuine positive decimal integer.

The verifier exist_affine_runs.py carries ordinary addition through each
constant run. For q!=9 the carry resets at the first position, so only the
first output digit can differ from the stable digit repeated afterwards.
For q=9 the incoming carry is transmitted unchanged. All run lengths are
exact integer affine expressions. A reverse-and-add q step then merges the
output digit-run list with its reversal; each required comparison between
run lengths is accepted only when its inequality holds for all k>=0.
Zero lengths are deleted only when identically zero. Branches changing with
k are rejected or retried after shifting the starting parameter.

Palindrome safety is checked for all k. If the digit-run symbol list is
asymmetric, no member is palindromic. Otherwise palindrome equality is a
system of integer-affine equations between reflected run lengths. The
checker rules out a common nonnegative integer root; checking only k=0
would be unsound, and explicit control cases catch that mistake.

A proposed positive certificate must satisfy, for some p>=1,
  F^p(Q_k)=Q_(k+1),
with a nonzero nonnegative growth vector and no palindromic numeric output
at any intermediate phase, for every k>=0. This implies an infinite safe
numeric orbit: choose an ordinary integer realizing Q_0, apply its first
addition, and use the exact q dynamics for all later phases. Positivity and
canonical widths must also hold. This is a mathematical certificate scheme,
not an instantiated decimal existence theorem or a Lean-verified checker.

Controls independently compare ordinary integer arithmetic for every seed
1..2999 in bases2,3,10,11. The same procedure rediscovers a known expanding
binary family in four steps and proves the affine identity symbolically.
It does not transfer that binary certificate to decimal.

The reproducible decimal search used random seed196,10,000 symmetric
multirun starts, up to240steps and at most100runs per state. Outcomes:
6,169 exceeded the run cap;3,795 reached a palindrome;36 reached the step
cap. No affine family was certified. A cap is an incomplete search outcome,
not a proof that a larger-period or more complicated construction fails.

Run:
  python3 exist_affine_runs.py --count 10000 --seconds 120

PERIOD-THREE CENTRAL CORES WITH FIXED EXTERIOR WIDTH

A separate exact functional graph uses full q words
  P ++ periodic(Q,3m+r) ++ reverse(P), m>=4,
where r is0,1,2 and Q has three coefficients satisfying
  Q_i=Q_((r-1-i) mod3).
The fixed residue under this reflection has an even coefficient, ensuring
validity of the odd-length members. The other repeated coefficient is any
integer0..18. This gives570 bulk states. P has fixed width k, positive first
coefficient, and entries0..18.

The core contains a non9 coefficient: a reflection-fixed coefficient is even.
Thus one complete period resets the carry. Beyond the first three core
positions, the output digit pattern and carries are exactly periodic with
period3. Reflection pairs this periodic interior with itself. Potential
exceptions lie within a bounded number of positions at either end. Checking
core lengths12+r and15+r covers both center parities and all boundary
positions; further triples only repeat the same arithmetic. The core can
therefore be updated exactly without placing a bound on its eventual length.

Each state has a unique successor or fails the required periodic-core shape.
States whose next ordinary reverse-add is palindromic are removed. Every
safe infinite path in this finite graph would contain a directed cycle; a
positive-growth cycle would give an inductive construction. The complete
functional-graph enumeration found no cycles for k=1,2,3,4, including all
temporal periods and all admissible overflow schedules in this model.
The largest graph has70,373,340 states and18,860,060 valid edges.

This excludes this bounded-exterior family; it does not exclude larger
exteriors, growing exteriors, other spatial periods, or decimal Lychrel
numbers. The graph algorithm is not formalized in Lean.

Independent check exist_period3_graph_check.py realizes each q word as a
literal positive decimal integer, performs integer reversal and addition,
and reproduces every edge/unsafe/core-failure count at k=1,2. At k=1 it also
checks larger core lengths21+r and24+r. It imports no discovery code.

Reproduce:
