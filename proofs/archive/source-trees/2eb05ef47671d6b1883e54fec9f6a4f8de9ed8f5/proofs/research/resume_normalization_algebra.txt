A direct run proof of the four-step carry normalization theorem

This proves an auxiliary normalization theorem, not decimal Lychrel
existence. It replaces the finite-state argument by explicit run identities.

Notation. For a symmetric mirrored-column-sum word q, write O for its
reverse-add pair-sum transformation when an overflow occurs, and N for
the transformation when it does not. Extend q by zeros outside its finite
support. A column below9 resets its outgoing carry to0; a column above9
resets it to1; a column9 transmits the incoming carry. For local formulas,
let R_i and L_i be the output digits obtained by carrying through q from
the left and right, respectively. Then

    N(q)_i = R_i+L_i,
    O(q)_i = R_i+L_(i-1).

Zero extension includes the extra leading1 automatically in the latter
formula. It also handles a9 run meeting an original endpoint.

Definition. A word is protected if each maximal nonempty run of9s has
one neighboring reset symbol0 and the other10, in either order. Endpoints
are interpreted using the exterior zeros. Let P_d be the protected words
whose other symbols belong to{0,...,d,10}, for d<=4.

Lemma1 (overflow on protected runs).
For consecutive non-9 symbols x,y, their output in O is

    rho(x)+rho(y),
    rho(x)=x if x<9, and rho(10)=1.

Indeed the two incoming carries across this adjacent pair are the reset
types of the opposite symbols, so the two output digits sum to
x+y-9([x=10]+[y=10]).

A protected run changes as follows. The displayed outputs occupy the
positions from the first old9 through the old right endpoint:

    0, 9^r, 10   ->   10, 9^(r-1), 0,
    10, 9^r, 0   ->   0, 9^(r-1), 10,       r>=1.

For the first orientation, the left-moving addition sees carry1 through
the run and the right-moving addition sees carry0. Thus the two streams
on the run are0 and9. At its two edges the sums are9+1=10 and0+0=0.
The other orientation interchanges the streams. This proves the formulas.

Consequently

    O(P_0) is contained in P_2,
    O(P_2) is contained in P_4.

No new9 can arise from a pair of ordinary symbols in either inclusion,
since its output is at most2 or4. The existing9 runs shorten by one and
retain opposite0/10 endpoints.

There is a further useful property of O(P_2): every4 has immediate
neighbors below9. Such a4 can only come from an adjacent pair2,2.
Neither of those2s can neighbor a9, because a protected9 run has only0
and10 as endpoints. The two output neighbors therefore also arise from
ordinary pairs, and are at most4.

Lemma2 (one non-overflow step).
For any protected9 run, the carries entering from its two ends are0
and1. Its N image is therefore9 at every position. A symbol10 produces
at most2. An ordinary symbol x produces2x plus its two incoming carries.
It follows that

    every symbol of N(P_2) is at most9;
    every symbol of N(O(P_2)) is at most9.

For the second statement, x<=3 produces at most8. The only additional
case is x=4; its immediate neighbors are below9 by Lemma1, so both
incoming carries are0 and its output is8.

Theorem (overflow normalization).
Let c_0=0,c_L=1 be the complete carry word of an actual reverse-addition.
Write a_i=c_(i+1) and b_i=c_(L-i), and define

    qhat_i=0  if a_i=b_i=0,
    qhat_i=10 if a_i=b_i=1,
    qhat_i=9  if a_i!=b_i.

The previously established carry-normalization lemma states that qhat is
symmetric, canonically realizable, and has exactly the carries c.
Here is why qhat belongs to P_0: on any maximal9 run, the two directional
carry values are different by construction. They are constant through
the run and equal to the types of its two nearest reset symbols. Those
reset types must therefore be different, so the endpoints are0 and10.
Exterior zero padding supplies a reset if a run meets an endpoint.

The outer symbol of qhat is either10 or9.

If it is10, the first addition overflows and the next outer pair sum
is1. Thus the first two pair transformations are O,N. By Lemmas1 and2,

    qhat in P_0  ->  O(qhat) in P_2  ->  N(O(qhat)) has all symbols<=9.

The following numeric reverse-addition is therefore palindromic.

If the outer symbol is9, the first addition overflows and the next outer
pair sum is10, forcing one more overflow; the following outer pair sum
is1, forcing no overflow. The first three pair transformations are O,O,N.
Again by the lemmas,

    qhat in P_0 -> O(qhat) in P_2 -> O(O(qhat)) in P_4
                -> N(O(O(qhat))) has all symbols<=9.

The following numeric reverse-addition is palindromic. This gives at most
four additions. The length-one case qhat=(10) is already covered by the
same argument.

Combining this with the earlier non-overflow normalization proves:
every complete first-step decimal carry word is shared by a positive
integer reaching a palindrome within at most four additions.

Example. qhat=(9,9,10,9,9) has a representative 10598, with

    10598 -> 100099 -> 1090100 -> 1101001 -> 2102012.

This representative first reaches a palindrome at the fourth addition.
It does not prove that four is the best possible bound when a different
representative with the same carry word may be chosen.
