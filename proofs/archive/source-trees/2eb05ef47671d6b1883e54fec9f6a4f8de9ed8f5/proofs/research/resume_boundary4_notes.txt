PERIOD-FOUR BULK INTERFACES: EXACT GRAPH RESULTS

Scope
-----
Eight growth segments, each consisting of one nonoverflow followed by one
overflow: 16 decimal reverse-and-add steps, eight added digits. A candidate
family repeats a four-symbol folded annulus with fixed finite exterior and
center interfaces. This graph examines exterior compatibility at arbitrary
interface width. It does not establish a finite seed by itself: a compatible
center and an inductive family identity would still be required.

Actual digit lift
-----------------
resume_boundary4_targets.py lifts each cyclic q bulk into actual left and right
digit arrays and carry streams. It checks all four spatial-cycle edges with the
original continuation_theory_multigrowth.transitions implementation. The three
bulk initial words are:
 A = (3,10,15,8)
 B = (15,10,3,8)
 C = (9,2,9,16).
For A, actual left/right digit pairs at the four time phases are:
 t0: L=(2,2,7,7), R=(1,8,8,1)
 t1: L=(4,1,5,8), R=(3,0,6,9)
 t2: L=(7,7,2,2), R=(8,1,1,8)
 t3: L=(5,8,4,1), R=(6,9,3,0).
These return at t4. The full target uses 16 temporal steps to allow the entire
four-symbol annulus to grow by one repetition on each folded half.

Complete results
----------------
The raw (unquotiented) backward spatial graph closes for B and C:
 B: 16384 states, 16384 edges, no required exterior state.
 C: 3744 states, 3744 edges, no required exterior state.
The original Python predecessor implementation independently exhausts exactly
these same graphs. Therefore B and C admit no exterior interface of any finite
width within this specific 16-step digit-interface model. Center searches cannot
repair their missing exterior.

Unresolved result
-----------------
A remains unresolved. Its raw backward search was capped after 3026480 states
and 143360 expansions. No exterior was found. This is not an exclusion.

A stronger exact search quotients states by cyclic rotation of the eight equal
two-step time segments. This rotation is a graph automorphism fixing the exterior.
Consequently quotient reachability to the orbit of a bulk target is equivalent
to original reachability to a temporally rotated bulk; a returned path would
need its rotations unfolded before constructing actual digits.

The quotient backward search reached 5000023 states and 2694144 expansions,
with completed earlier breadth layers ending at 2,140,32912,694366,2017617.
Its five-million-state cap was reached at layer 5; queue exhaustion did not occur.
The quotient forward search reached 5000297 states and 4599296 expansions,
with the cap reached at layer 32. Neither endpoint set intersects the other.
Both searches remain incomplete. Runtime was under ten seconds for each stated
search, below the 30-second ceilings. State ceilings, not runtime, caused stops.

The first three forward quotient cumulative layer sizes, 73,537,673, independently
match the original Python transition generator. This is implementation validation,
not a Lean proof or evidence that the infinite-existence problem has been solved.

Follow-up: uniform central-core gluing
-------------------------------------
Two DIFFERENT interface frames were tested and must not be conflated.

(1) Stationary interface in fixed least-significant offsets (velocity zero):
The original exterior-frame graph imposes dr_final=dr_initial. Starting backward
from uniform actual digit3 or6 targets produces exactly256 raw states/256edges,
or36 cyclic-rotation quotient states. Neither contains an A state. This rules
out stationary A-to-uniform gluing, where the growing length is absorbed into
the central uniform domain. It does not itself address a moving interface.
Results: resume_boundary4_center_results.json and _center_python.json.

(2) Interface advancing four columns in16steps, viewed in a center-fixed frame:
resume_boundary4_interior.py derives the correct alternating left/right growth
shift. Group eight growth segments into four pairs. Each pair fixes the even
segment's right input x_k and left output y_k; the odd segment's selected left
input becomes the new y_k, and its right output becomes the next x_(k+1).
Cyclically link odd left outputs to subsequent even left inputs. Carries propagate
outward with left input/right output known (the 'I' local relation).
For two segments this is exactly continuation_theory_graph.transitions(side='I');
100 chosen-state comparisons agree, and all four spatial edges of each lifted
A/B/C bulk cycle are checked. Center-frame bulk phase at segment j and spatial
offset i uses periodic index floor(j/2)-i modulo4.
Starting forward from uniform3 or6 core states, this graph also exhausts at
256states/256edges, with none of A,B,C reached. Thus the moving-by-four version
of uniform-core gluing is separately excluded at arbitrary interface width.
Results: resume_boundary4_interior_results.json.

These exclusions do not rule out nonuniform finite central cores, different
uniform cores, different growth clocks, or moving interfaces with other speeds.
Neither interface closure has been formalized in Lean.

Follow-up: exclusion of all finite 16-step-return central cores for A
------------------------------------------------------------------
The corrected interior graph can search from an A annulus toward the center,
without preselecting uniform central digits. Reverse each local transition by
using the E half-step relation and reversing the alternating digit constraints.
The exact center-head predicate for state digits (x_k,y_k) and carry masks is:
 (a) left and right carry masks agree in every even-numbered segment;
 (b) in each odd-numbered segment, start with central digit y_k and apply
     x := (2*x + input_carry) mod10 for both time steps. Its output carries
     must be the recorded left mask and its final digit the next x_(k+1).
This is the ordinary central-column addition law. For two segments it exactly
specializes to the earlier heads(base,pa,pb,'I') enumeration.

Backward closure from A exhausts at12544 raw states/12544edges and contains no
center head. An independent C++ implementation quotients only by rotations of
TWO segments (preserving center parity), giving3136 states/3136edges, also
completely exhausted. No state or runtime cap was approached. The Python run
reproduces the raw closure independently using the original half-step generator.

Parity/phase coverage: the displayed graph starts before N with even digit
length. A hypothetical odd-length family can instead be examined two steps
later, after one growth, when its length is even. The bulk then changes from
A=(3,10,15,8) to (15,8,3,10), a spatial rotation already included in A's four
bulk states. The equality of the two target SCCs is checked explicitly.
Thus this obstruction covers both initial center parities for the stated
16-step-return A-annulus family.

Precisely, this excludes a fixed finite center pattern which returns after16
steps while the two period-four A annuli each lengthen by four symbols. It does
not exclude a center with a nontrivial 16-step return cycle and total temporal
period32,48,...; it does not exclude a growing nonperiodic center or other bulks.
The surviving A exterior search is therefore insufficient to construct this
particular16-step family, even if an exterior path were eventually found.

Follow-up: nontrivial finite-center return cycles
------------------------------------------------
A finite central core need not be a fixed point after16 steps; a cycle of k
returns would give temporal period16k. This possibility was tested separately.
For each of four bulk rotations and both center parities, the exact deterministic
16-step local return map was exhausted on four mirrored core pairs (eight or
nine full q symbols). A transition is retained only if every symbol outside the
chosen core window returns to the prescribed A reservoir. Cycles of every length
in this finite return graph are then checked, not only fixed points.

Total states over all eight cases:5734124.
Retained return edges:144. All other states leave the allowed core window.
Cycles: none. Every retained edge exits on its very next return, so the maximum
internal chain length is1.
Every one of the144 retained edges was independently recomputed with the Python
local-update routine in resume_defect_center.py. An additional128 varied random
return-map checks agree. No conclusion about larger core widths is drawn.

Files: resume_boundary4_center_cycles.cpp, _center_cycles_results.json,
_center_cycles_validation.json. This bounded-center, all-return-period result
is logically separate from the arbitrary-core-width, single-period16 graph
exclusion above. Neither is a decimal Lychrel existence or nonexistence proof.
