## The 218 result

```lean
theorem Agent118.Finite218.ancestry_bound34 :
    ∀ A P t, 0 < A → PalindromeStarts3 2 1 8 P → orbit A t = P → t ≤ 34
theorem Agent118.Finite218.no_196_218_palindrome :
    ∀ t, ¬ PalindromeStarts3 2 1 8 (orbit 196 t)
```

In words: if some positive integer reaches, after `t` reverse-and-add steps, a palindrome whose decimal
numeral begins with 218 (any length, any interior digits), then `t ≤ 34`; since the first 100 iterates
of 196 are not palindromes, no iterate of 196 at any time is such a palindrome. This is the bound of the
written seven-column certificate (`certificate_218.json`, written bound 34), now kernel-checked. It is
not claimed to be optimal, and it excludes one restricted palindrome family only.

`cert218/` is generated by `generate_instance.py 218` from the frozen JSON (hash-checked against
`SHA256SUMS.txt`). The generator is untrusted: the kernel re-runs the complete executable inverse for every
stored row (`decide +kernel`), the exact short update for all 10,467 short words, and full-word lookups for
all 10,002 initial words. Layout: 38,587 nodes in a lookup tree of 1,024 leaves and 1,023 interior rows;
16 data modules, 105 row modules (8 dense leaves are checked row by row), 10 initial modules, 18 short
modules. Dev build: 2,006 CPU-seconds in total, peak resident memory 2.3 GiB.

## What `PrefixAncestry.lean` proves

For digits `a, b, c` with `2 ≤ a`, write `PalindromeStarts3 a b c P` for: `P` is a decimal
palindrome whose canonical numeral begins with `a, b, c` (any width, any interior digits).
`palindromeStarts3_739_iff` checks that `PalindromeStarts3 7 3 9` is definitionally Agent #104's
accepted `PalindromeStarts739`.

`ancestry_bound_of_finite_checks a b c bound`: if a rank tree satisfies

1. `CheckedRows tree (longPred 7)`: every stored long row's complete executable inverse lies in the
   tree with strictly smaller rank (Agent #104's interface, unchanged);
2. `ShortDescent tree`: for each of the 10,467 exact admissible short words `s` (widths 1 to 6), if the
   exact image `nextWord s` lies in the tree with rank `r`, then `s` lies in the tree with rank `< r`;
3. every word of `targetInitialWords a b c` (the admitted short palindromic completions of the prefix,
   and the 10,000 seven-column words `a,b,c,d3,d4,d5,d6`) lies in the tree with rank `≤ bound`;

then for every positive integer `A` and every `t`, `orbit A t = P` with `PalindromeStarts3 a b c P`
implies `t ≤ bound + 1`. `no_196_of_finite_checks` adds `bound + 1 ≤ 100` and concludes that no
`orbit 196 t` lies in the family, using the existing kernel-checked fact that the first 100 iterates
of 196 are not palindromes.

Premise 2 replaces Agent #104's premise "no short image lies in the tree" (`shortDescent_of_exclusion`
shows the old premise implies the new one). The old premise holds for 739 but fails for the other
certificates: replaying the frozen JSON certificates with their own Python semantics gives short-source
edges into the rank tree 218: 1, 777: 17, 217: 3, 620: 6, 739: 0, all with strict rank descent.
