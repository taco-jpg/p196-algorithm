Third no-overflow layer checkpoint:
  astra_counting_nooverflow_depth.py
  astra_counting_nooverflow_depth_results.json

For target half-words beginning14 and then using only5/14, the exact
determinized automata for d=1,2,3 incoming no-overflow layers have4,16,65
states. For d=2 all16 carry states form one closed component. This is
the source of the main theorem's arbitrary-prefix correction method.
For d=3 there are64 carry states and an empty rejecting state. The
64-state component has leakage to rejection, so that particular
all-prefix correction argument fails. This observation is specific to
the5/14 alphabet and the all-no-overflow incoming schedule; it supplies
no upper bound on fibers allowing other alphabets or overflow schedules.
