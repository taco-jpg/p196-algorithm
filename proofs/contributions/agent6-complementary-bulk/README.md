## 1. Autonomous exterior factor

Write all words least-significant first. Let `c` be a positive nonneutral
phase, `k=1[c>=10]`, `t=c-9k`, and `c'=2t`. For an exterior block `B`, compute

```
normalize(B, 0)       = (D, e)
normalize(reverse(B), k) = (R, gamma)
u = c + e - 10k
```

The raw exterior after the actual whole-word step is

```
(D ++ [u]) + (reverse(R) ++ [t])   when gamma = 0,
(D ++ [u]) + ([1] ++ reverse(R))   when gamma = 1.
```

Addition is coordinatewise. Remove the maximal `c'` suffix of this raw word
to obtain `B'`. Define `E(c,B)=(c',B')`.

The existing all-gap formulas (3), (6), (7), and (10) give this factor
EXACTLY: the rightmost `c` band resets the carry entering `reverse(B)` to
`k`, independently of its length and every inner interface. The other raw
exterior input is normalization of `B` from carry zero. Neither `A`, `C`,
`g`, nor `h` appears. In particular `gamma` is computed from the actual source;
it is not a freely selected control bit. Projection to `(c,B)` therefore
commutes with every legal full quotient transition.

Canonical trimmed exteriors have coefficients in `0,...,18`, a positive
first coefficient when nonempty, and no last coefficient equal to `c`.
The output has these same properties. Empty blocks remain legal.

Every phase becomes even after one step. Hence every phase on a returned
cycle lies in `{2,4,6,8,10,12,14,16}`. The two phase cycles have lengths two
and six. The finite computation below exhausts all eight periodic phases,
not just starting phases 2 and 6. Its sharp first-exit bounds apply directly
to these even-phase states; they are not asserted unchanged for odd starting
phases.

## 2. Complete finite domains and independent replay

Let `D_m` contain all canonical trimmed exteriors with `|B|<=m` over those
eight phases. `D_0` has eight states. For `m>=1`,

```
|D_m| = 8 * 18 * 19^(m-1).
```

Proof of completeness/counting: pad a canonical `B` on its right with `c`
until it has length exactly `m`. This is a bijection to length-`m` words
with first coefficient in `1,...,18` and other coefficients in `0,...,18`.
Its inverse removes the maximal `c` suffix. The empty block corresponds to
the all-`c` padded word. This proof also covers all shorter exteriors.

The construction enumerates variable-length words. The replay independently
enumerates padded fixed-width words. Each edge is recomputed using the
ordinary integer value of the canonical symmetric coefficient word

```
B ++ [c,c] ++ [18-c,18-c,18-c,18-c] ++ [c,c] ++ reverse(B).
```

The replay extracts the first `|B|+1` mirrored digit sums from its canonical
decimal output, then trims the new phase. This uses integer powers, decimal
conversion, and reflection, NOT the search normalizer. The exact factor
argument above is why this single small-gap realization gives the same
exterior edge for arbitrary legal inner interfaces and gaps.

A rank is constructed from first-exit distance, with rank zero outside the
cap. Every state is then independently checked against

```
r(s) = 1 + r(E(s)).
```

A repeated interior state would reject the negative certificate rather than
be silently truncated. These identities prove acyclicity and the exit bound.
A SHA-256 digest commits to the ordered state/edge/overflow/rank transcript;
the complete transcript is reproducibly generated by the published code,
not supplied as an opaque precomputed table.
