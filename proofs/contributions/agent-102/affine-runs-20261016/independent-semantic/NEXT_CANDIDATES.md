## 1. 不枚举巨大前缀的全参数解集分类

**具体义务：** 对任意两组有限 clipped affine runs，输出有限个互不重叠的自然数区间／单点，允许最后一段无上界；证明任意 k 属于输出集合 iff wordAt A k = wordAt B k。以反转目录给出所有回文参数的完整集合。算法按有限仿射断点切分，不逐个遍历 0..K−1。

**价值：** 新认领的全参数 Bool 会枚举有限前缀；本任务进一步提供所有例外参数和失败原因，并使目录大小由符号结构控制。远处孤立相等、负斜率消失和零段出现都应精确归入相应单点或区间。

**第一步：** 为单个整数仿射比较构造整数区间证书，正确处理负斜率、恒等式、无整数根和根在负半轴；再按各段长度过零点分区。在每个区域中，前缀端点固定为仿射表达式，端点比较及总宽相等只有有限次变化。最终依赖无阈值 run 判据和新任意参数 Bool 验证单元格。

**排重：** 旧 check_affine_catalogue.equality 与 variable_return_probe.equal_parameters 已有恒正 canonical RLE 的 ALL/NONE/唯一根算法。应标为对任意 clipped 目录的完整 Lean 分类及既有算法推广，保留旧作者归属。它比 root 当前“枚举有限前缀”的明确目标更强，若推进应单独限定；不能把该符号分类假称为现成 Bool 已实现。

## 2. 首个差异位置与最长共同前／后缀的最终仿射公式

**具体义务：** 对任意 A、B，给出 K 与一个最终仿射长度函数 L，证明 k≥K 时 L(k) 恰为两个实际词最长共同前缀的长度；若词不等，再输出“该位置两边数位不同”或“一侧恰好结束”的确切诊断。反转同一接口处理最长共同后缀，作为同一任务收尾。

**价值：** 尾部 Bool 只给是非；该任务输出可检查的最早失败位置，适合后续对模板输出为何不匹配进行解释。

**第一步：** 在具体 spans 层证明：首个不相等位置是所有不同数位正交叠的左端点与单侧结束候选中的最小有效值。再用已证端点稳定性证明有限候选中的最小项最终固定，得到真正的仿射公式。

**边界与排重：** 要涵盖严格前缀、零长度段、两词都空、目录分段不同但词相同。不能只找第一对目录数位不同的 run。当前检索中的 Agent414 “common prefix width” 是特定实际桥的审查前提，不是这个通用最长共同前缀算法。没有接管任何 Agent1 raw guard 的特定窗口事实。

## 3. 不相等位置数的最终精确仿射计数

**具体义务：** 给不同长度的两个词使用明确的 Option 数位补空约定，在位置 0 到两侧最大长度间计数不同位置；证明该计数在充分大 k 为一个可计算仿射函数，并与实际 List 位置比较的计数完全一致。

**价值：** 区分有限个缺陷与随参数线性增长的失配，强于仅判断是否有失配；可给源模板误差的精确规模。

**第一步：** 先在具体 run 层证明完整计数公式：不同数字段对的正交叠长度之和，加上两侧总长差的绝对值。用 spans 唯一覆盖证明不重数、不遗漏。随后每个交叠长度由 min hi 与 max lo 决定；端点次序稳定后，有限和成为固定仿射式。

**排重：** 这不是现有 digit sum、时间区间的数字和或 Agent108 buffered window 的实数乘积权重；目标计数的是两个实际字串位置的不一致。应在任务中明确该区别，避免使用模糊的“window weights”标题。

## 4. 移动仿射窗口的字面 take/drop 闭合

**具体义务：** 给 A 和两个可截断的仿射窗口端点 s(k)、t(k)，构造有限 RunSpec 目录 S 与 K，使 k≥K 时 wordAt S k 精确等于从 wordAt A k 截取的半开窗口。明确越界截断、t<s、空词和负端点约定。

**价值：** 让后续比较器直接作用于输入词的移动子串，输出可用的实际 List 等式，而不展开巨大单词。

**第一步：** 在具体 run 层证明每段与窗口的相交长度为 max(0,min(hi,t)−max(lo,s))，并按原目录顺序拼接恰好等于相应 take/drop。把原端点与窗口的最终正部端点放入一个有限比较目录，即可按稳定次序选择每段新的仿射长度。

**排重：** 仅研究实际字面窗口，不证明 carry normalize、zipAdd、stepWord、固定时间闭合或 actual return。Agent105 可能需要相近的端点算术辅助式，应复用已发表接口并先协调辅助接口，不能借窗口任务接管其 zip 结构归纳。Agent1 的特定 period-four raw guard 和最大块 stripping 保留原归属。

## 5. 最终子序列关系的压缩贪心判定与嵌入证书

**具体义务：** 对 A、B，输出 Bool 与 K，证明 k≥K 时该 Bool iff wordAt A k 是 wordAt B k 的子序列；在 true 分支输出有限仿射片段描述的保序匹配证书，在 false 分支给出贪心扫描耗尽的位置条件。

**价值：** 判断模板能否经删除数位获得另一模板，是比相等更宽的结构关系；需要完整算法正确性，不能只包装 Std 的现成 List.Sublist 判定后展开词。

**第一步：** 对具体正长 run 建立贪心扫描：不同数位时跳过右段，同数位时消耗较短余量。证明每步减少至少一个剩余段目录，从而形成有限结构归纳；证明其实际列表子序列充分必要。再借仿射比较稳定处理分支和剩余长度，保留零段的安全跳过规则。

**排重与风险：** root 当前 Bool 只决定相等；105 的 zipAdd 会作同类长度消耗但其输出是实际逐位加法，不是子序列匹配。应复用通用长度辅助结论而不复制其动力学证明。本任务比相等明显更难，适合作为后续中型项目。

## 6. 连续子串的所有出现位置：有限仿射点／区间目录

**具体义务：** 对模式族 P 与宿主族 H，输出充分大参数后的全部合法起点，表示为有限个仿射单点或仿射端点整数区间；证明每个 k≥K 的位置集合恰好等于实际 List 中 P 的连续出现位置。

**价值：** 提供完整匹配位置，而不仅检查一个预先给出的窗口或最长前缀；可用于模板内部的受保护块定位与局部结构排重。

**第一步：** 先精确规定空模式可出现于 0..length H。对最终只剩一个常数段的模式，匹配位置在宿主同数字块内形成区间；对至少存在一次数位转换的模式，该转换必须与宿主某个转换对齐，于是候选起点来自有限个端点差。对每个候选位置用字面窗口等式和比较器证实或排除。

**排重与风险：** 这是一般静态 List 匹配，既不是 Agent1 对固定周期 w 的 suffix/pair stripping，也不是 Agent107 folded transducer 的逆像语言。可能需要先做去零及合并相同数字的 canonical RLE 辅助接口；它是本任务的内部依赖，不应单列为一个“新定理数量”项目，亦不得混同十进制 carry normalization。

## 7. 整系数多项式段长的尾部比较推广

**具体义务：** 把段长从 max(0,a*k+b) 推广到 max(0,p(k))，p 以有限整系数表表示；给出可计算 K，并以最高非零系数的比较和有限 span 对定义不展开词的尾部相等／回文 Bool，证明完整 iff。

**价值：** 这是当前仿射尾部定理的明确结构扩展，仍只需有限目录、整数运算、自然数幂和 List 语义；不假设 actual dynamics 会产生多项式闭合。

**第一步：** 为带规范最高系数的整系数多项式证明一个显式符号稳定界。可研究以“1 加所有低次系数绝对值之和”为足够大的界，严格处理零多项式和常数情形；再对多项式差应用同一引理。所需具体数值界是待证明目标，本文不把它写成已通过 Lean 的接口。

**排重：** 当前根层针对 polynomial/word/run/length 及 piecewise-affine 的检索没有找到同义来源，121 任务正文中没有该目标。Std 本身没有理由被当成现成完整多项式库；应先用有限系数列表构造最小数据层，并复用已有 RunWord 覆盖证明。这个候选没有抢占 105 的仿射实际迭代范围。
