## 明确阈值的审查

每个 run 的长度阈值为该长度仿射式截距绝对值加一。`lengthCutoff` 取这些有限阈值的最大值，空表取零。在该阈值以后，`positivePart.eval` 严格等于实际长度表达式的 `Int.toNat` 转换；负斜率和负常数段贡献零，零长度段仍存在于区间列表中。

`endpoints A ++ endpoints B` 显式包含两侧总宽及每个保存区间的左右端点。`pairCutoff` 枚举该有限表中每个有序端点对的 `compareCutoff`，并取最大值。`equalityCutoff` 同时支配两侧长度阈值与这个端点对阈值。

因此，当 `k ≥ equalityCutoff A B` 时，长度截断公式已经正确，保存端点求值已经非负，所需端点大小比较也已经稳定。阈值无需段长正、相邻数字不同、段数非零或数字属于特定进制。

## 词相等稳定性的审查

`wordAt_eq_iff_spans` 将实际 `wordAt` 相等精确转换为两部分：总长度相等，以及每对实际交叠的保存区间数字相等。它直接使用 `spanSpecs_at` 的完整区间列表相等和词模块的精确覆盖定理，没有按字母集合或总宽替代实际词相等。

总宽比较由 `width_eq_stable` 保持。两侧总宽均已收入端点列表，因此对应的比较阈值确实受 `equalityCutoff` 支配。

`Span.overlaps_iff_four` 将交叠准确展开为四个严格不等式：左段正长、两个交叉不等式和右段正长。保留两个正长条件对于零长度段是必要的；源码全部保留。`span_overlap_stable` 对这四项逐一使用端点比较稳定性。

保存区间列表和数字本身不依赖参数。于是长度相等和每个区间对的交叠数字约束均可在 `k` 与阈值之间双向搬运，得到完整的 `wordAt_eq_stable`。它把任意尾部参数的整词相等与一个明确参数处的整词相等严格等同，并非依赖有限样本猜测无限结论。

## 真、假两种尾部结论

`equalOnTail` 使用可判定列表相等，在明确阈值处返回布尔值。`equalOnTail_spec` 的真分支给出阈值以后每个参数都相等；反向只需把全称结论用于阈值本身。

`unequalOnTail_spec` 的假分支给出阈值以后每个参数都不相等。证明通过 `wordAt_eq_stable` 把任意假设的尾部相等搬回阈值，从而与阈值处不相等矛盾。此处确实证明了整个尾部均不等，而不只是某个尾部位置不等。

`equality_before_cutoff_of_tail_mismatch` 的范围正确：若布尔值为假而某个参数处发生相等，则该参数严格小于阈值。它不声称所有阈值前参数都相等，也不声称已经枚举有限前缀。

## 回文分支

`wordAt_reverse` 使用运行列表反序与映射反序的一致性，以及每个 `replicate` 块反序不变，严格得到实际词反序。空表和零长度块均由同一列表等式处理。

`palindromeCutoff A` 正是 `equalityCutoff A A.reverse`。回文稳定性、最终全为回文的真分支，以及最终全不为回文的假分支，分别由已证明的整词相等、真尾部和假尾部结论实例化得到；无需附加表示规范化假设。
