## `moving_fixed_stable_iff` 的必要方向

`moving` 在参数 `k` 处展开为长度 `k` 的全 1 词，`fixed N` 展开为长度 `N` 的全 1 词。`moving_fixed_eq_iff` 通过真实列表长度证明两词相等当且仅当 `k = N`，包含 `k = 0` 和 `N = 0`。

稳定条件是：所有 `k ≥ K` 处的相等真假都与 `K` 处相同。必要方向没有把 `K ≤ N` 的情形略去：

1. 假设稳定且 `N < K` 不成立，得 `K ≤ N`。
2. 将稳定假设用于 `k = N`。该处相等为真，所以 `K` 处也相等，得 `K = N`。
3. 再用于 `k = N + 1`，利用 `K = N` 得到 `N + 1 = N`，矛盾。

因此必须 `N < K`。充分方向中 `k ≥ K > N`，所以 `k = N` 和 `K = N` 均为假，所需等价成立。该证明涵盖所有自然数退化情形。

由此得到这一模板对的最小稳定阈值是 `N + 1`。`compareCutoff_moving_fixed` 也表明这一对标量的比较界恰好是 `N + 1`；本模块没有声称整体 `equalityCutoff` 对所有模板都最小。

## 无统一阈值的量词顺序

`no_uniform_wordAt_cutoff` 否定的是：

`∃ K, ∀ A B, ∀ k ≥ K, Eq(A,B,k) ↔ Eq(A,B,K)`。

它没有否定允许阈值依赖模板对的结论 `∀ A B, ∃ K, ...`，因此与既有尾部稳定性定理完全相容。

`equality_changes_arbitrarily_late` 的见证依赖预先指定的 `K`：选择 `A = moving`、`B = fixed K`、`k = K`。两词在 `K` 处相等，在 `K + 1` 处不等。因此任何预先选定、声称同时适用于全部模板对的常数界都失败。这一家族的数字、段数和斜率固定，仅固定长度的截距随 `K` 变化。

边界模块仅导入字面词与标量算术模块，没有导入总体尾部稳定模块。上述反例证明不循环依赖它所刻画边界的总体结论。

## 零区间实际 run 反例

反例中的零段并非随意挑出的孤立区间，而是实际展开区间列表的成员：

| run 列表 | 实际展开词 | 相关区间 |
| --- | --- | --- |
| `[(9,1), (7,0), (9,1)]` | `[9,9]` | 数字 7 的 `[1,1)` |
| `[(9,2)]` | `[9,9]` | 数字 9 的 `[0,2)` |

这里每个 run 的二元组依次表示数字与长度。两个实际词完全相同，但所选区间的两条交叉严格不等式 `1 < 2` 和 `0 < 1` 均成立，数字 7 和 9 却不同。真正的交叠条件为 `max 1 0 < min 1 2`，即 `1 < 1`，所以为假。

`zero_span_realized` 同时证明两个区间的真实成员关系与实际词相等。`cross_inequalities_false_negative` 随后使用这些成员关系和严格不等式，证明只检查两条交叉不等式的全称规则会错误拒绝这一对相同词。它确实验证了保留正长度条件的必要性。

## 其余边界见证

`run_structure_counterexample` 使用正长度段说明不同 run 结构可以表示同一个字面词；没有依赖零长度段制造结构差异。

`overlap_digits_without_width` 除证明所有实际交叠段数字相同外，还显式提供至少一对真实交叠区间。两词总宽仍不同、词仍不等，因此不能删掉词相等判据中的总宽条件。

这些结论限于字面 run 词及其仿射参数，不涉及真实十进制进位迭代或 P196 全局命题。
