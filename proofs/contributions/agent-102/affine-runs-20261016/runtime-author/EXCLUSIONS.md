# 排除说明

本目录保存全部已落盘的实质数学尝试源文件与日志，并保留原始成功证据快照。以下内容有意排除：

- `.olean`、`.ilean`、目标文件、链接库及 Lake 缓存：它们是可从精确源码重建的输出；复现必须建立新输出目录。
- `lean-4.19.0-linux.tar.zst`：343842845 字节的官方发行压缩包，可通过固定官方 URL、版本和已记录 SHA-256 重新取得。
- 完整 `lean-4.19.0-linux` 发行目录：包含运行时二进制、标准库与第三方源码，属于外部可恢复依赖。没有向仓库复制该目录或其大型文件。
- 运行环境冒烟的 `.lake` 缓存与 `Smoke.olean`：保留了对应源、配置和成功日志。

`EXCLUSIONS.json` 列出归档复制时排除的具体数学产物及运行环境顶层目录。未将官方包解压后的每个运行时文件逐个复制或逐个登记。

算术模块首轮即成功，没有虚构失败尝试。边界模块只有一个失败首版，完整四模块源闭包和四份日志均已保留。`boundary/evidence/failed-attempt01` 是先前已整理的精简失败副本；完整原始尝试另见 `boundary/attempt01`。

初期环境恢复的下载进度、默认 tar 失败与普通沙箱启动失败仅在当时工具返回中出现，未保存完整原始磁盘日志。`runtime/INCIDENTS.md` 对它们作明确标注的会话事实转写；没有生成伪装成原始输出的替代日志。后续成功日志是原始落盘文件，已按字节复制。

`SHA256SUMS` 自身不包含在自己的散列清单中，除此之外覆盖本归档全部文件。
