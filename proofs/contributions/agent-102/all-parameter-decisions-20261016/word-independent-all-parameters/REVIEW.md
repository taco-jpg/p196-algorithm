## 参数域的完整划分

记 `K = equalityCutoff A B`，`P(k)` 表示 `wordAt A k = wordAt B k`。

有限前缀使用 `List.range K`。源码通过 `List.mem_range` 精确得到 `k < K`，而尾部接口要求 `K ≤ k`。两者覆盖全部自然数，且在阈值处不重叠：

- `k = K` 不在有限前缀中，明确属于尾部。
- `k = 0` 在 `0 < K` 时由前缀处理；在 `K ≤ 0` 时由尾部处理。
- `List.range 0` 的全称检查为真、存在检查为假；相应尾部从 0 开始，因此不会漏掉零参数。

上述证明不依赖额外的 `K > 0` 假设。有限前缀调用的 `equalAt_eq_true_iff` 对任意参数成立，因此阈值以前的负仿射长度也按实际 `Int.toNat` 规则处理，没有错误套用尾部长度公式。

## 全称与存在组合

实际源码的组合关系正确：

| 布尔定义 | 计算组合 | 已证明含义 |
| --- | --- | --- |
| `allEqual` | 尾部真且有限前缀全部真 | `∀ k, P(k)` |
| `someEqual` | 尾部真或有限前缀存在真 | `∃ k, P(k)` |
| `allUnequal` | `!someEqual` | `∀ k, ¬P(k)` |
| `someUnequal` | `!allEqual` | `∃ k, ¬P(k)` |

`allEqual_spec` 通过 `K ≤ k` 的分类，在尾部全称规格与有限前缀全称规格之间选择，没有将有限列表的全称命题误当成所有自然数的全称命题。

`someEqual_spec` 的两个方向尤其需要尾部稳定性：

1. 尾部布尔值为真时，源码明确选择 `k = K` 作为实际自然数见证，并使用 `Nat.le_refl` 满足尾部条件。
2. 如果给定相等见证位于尾部，源码调用 `fastEqualOnTail_iff_wordAt A B k hk` 的反向，推回尾部布尔值为真。这里使用的是对任意尾部单点的精确等价，不是把一般的“尾部存在一个相等点”无条件提升为“整个尾部都相等”。
3. 如果见证位于阈值之前，它被放回 `List.range K` 的有限存在检查。

因此存在性组合既不会漏掉只出现在前缀的相等，也不会错误接受一个不存在任何实际参数见证的尾部结果。

## 补运算的位置

源码把“所有参数都不等”定义为“并不存在某个参数相等”，即 `allUnequal = !someEqual`。它把“存在某个参数不等”定义为“并非所有参数都相等”，即 `someUnequal = !allEqual`。

两个补运算都放在正确的整个存在/全称结果外层；没有把 `!allEqual` 误称为全不等，也没有把 `!someEqual` 误称为存在不等。

`allUnequal_spec` 对相等见证直接产生矛盾，反向通过布尔值分情况证明。`someUnequal_spec` 显式使用经典逻辑：若不存在不等见证，则逐个参数推出相等，进而由 `allEqual_spec` 得到 `allEqual = true`，与补值为真矛盾。

经典逻辑只用于规格定理的证明，没有被放进这些可执行布尔定义中。

## 假结果与实际反例存在性

`allEqual_false_iff` 的最终陈述是：

`allEqual A B = false ↔ ∃ k : Nat, wordAt A k ≠ wordAt B k`。

它通过 `someUnequal_spec` 和正确的 `Bool.not_eq_true'` 推出。已核查 Lean 标准库中带撇号引理把 `(!b) = true` 改写为 `b = false`，与当前定义的布尔否定精确匹配。

`someEqual_false_iff` 相应给出：

`someEqual A B = false ↔ ∀ k : Nat, wordAt A k ≠ wordAt B k`。

这两条没有把“没有证明全称结论”当成计算结果为假，也没有把存在反例弱化成双重否定。它们确实分别证明实际自然数反例存在和整个参数域均不等。

接口返回的是布尔判定，规格证明反例存在性；当前源码没有另行返回反例下标。不能把存在性规格描述为已实现了见证提取函数。

## 回文与非回文规格

四个回文布尔定义分别把两模板参数设为 `A` 与 `A.reverse`，并使用已证明的实际词等式 `wordAt A.reverse k = (wordAt A k).reverse`。

因此全为回文、存在回文、全不为回文、存在非回文分别继承上面的四种正确量词结构。`allPalindromic_false_iff` 给出某个自然数参数上的实际非回文见证；`somePalindromic_false_iff` 给出所有参数都非回文。这里没有以 run 列表的语法反序相等替代实际展开词的回文性质。

## 可执行分支与范围

有限前缀只枚举参数 `0, ..., K-1` 并调用压缩的 `equalAt`。尾部调用仿射系数检查器 `fastEqualOnTail`。本模块的布尔定义没有调用 `wordAt` 或 `List.replicate` 来展开数字词；它仍会构造有限参数前缀，因而不应额外宣称运行代价与阈值大小无关。

所有量词都是静态模板族的自然数参数，不是反转加法迭代时间。当前源码及其规格不包含真实十进制迭代闭包或 P196 全局命题。
