# 排除与保留说明

本证据包保留了两次实质尝试的完整十模块源码、各模块原始 stdout/stderr、
实际 Lean 子进程命令及退出码、成功版本的全部三个审计程序与日志、
版本与可执行文件散列、可复现脚本、修改差异和来源映射。

明确排除的内容：

- `.olean` 及其他编译产物：均可由已保留的确切源码和官方 Lean 4.19.0 重建。
  它们仍位于原临时构建目录中，没有被删除或冒充为源码证据。
- 构建目录内重复的 `.lean` 副本：与相应 `source` 快照字节相同，包内保留一份即可。
- Lean/Lake 可执行文件、标准库二进制与官方约 344 MB 发行压缩包：它们属于可恢复的运行时，
  不作为仓库贡献发布；实际版本与 Lean 可执行文件散列已记录。
- 环境变量全量转储、凭据和代理配置：本任务未生成这种转储，也未复制或更改任何凭据。
- 旧 claim 的 Arithmetic、Boundary 作者历史与 Decision 审查历史：早已单独封存；
  本包保留当前构建所需的冻结源码，但不将旧记录伪装成本 claim 的新尝试。
- 非实质的只读目录探查、工具返回元数据：不作为数学证据复制；真实失败编译源与日志无遗漏。

`COPY_ORIGINS.json` 对每个按字节复制的原始文件记录绝对来源、相对目标、大小和 SHA256。
报告与总清单是本次整理生成的说明文件，未声称它们是原始编译器输出。
