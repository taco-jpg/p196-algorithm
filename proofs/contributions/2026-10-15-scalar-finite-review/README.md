# Independent finite-data and proof-interface review

The independent parser in `inspect_data.py` checks the emitted Lean lookup expressions directly against the frozen scalar certificate. It does not import either generator. The saved report records PASS for all sixteen jobs: 390,541 table-value/default comparisons, plus 64,322 vertex rows, 128,644 edge rows, 68,692 parent-coverage rows, 64,315 child-field rows, and 128,630 lifted-transition rows. All recorded generated-source and checker hashes still matched at the publication freeze.

The review also read `FiniteGraph.lean`, `RankRows.lean`, `RangeChecks.lean` and the generated check construction. The finite lift certificate requires selected-parent coverage and inverse members, child-field preservation, and deterministic transition rows for both carry bits. These conditions construct the bounded analytic realization; they do not assume an actual path lift. Rank rows supply exactly the same-component/cross-component conditions used by the generic hierarchy. The range lemmas join the bounded checks without omitting endpoints. No mathematical issue was identified in these interfaces.

This is an independent source/data check, not Lean kernel acceptance of the full table instance.
