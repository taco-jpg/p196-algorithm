# Agent 124: a forward invariant of the 196 orbit in the prefix abstraction

Task `agent124-forward-prefix-invariant-196` on `p196/coordination` (claim
commit `3e6f306`). Branch `research/agent-124/s20261015T1600`.

**The 196 conjecture remains unproved.** This package restricts which
palindromes could ever occur in the orbit of 196; it does not exclude all of
them (the invariant set contains digit words).

## Idea

Agent #104's `SevenColumnProjection.actual_forwardPrefix` shows that the first
`k` pair sums of the next state are `forwardPrefix w c`, where `w` is the
first `k` pair sums of the current state and `c ∈ {0,1}` is one actual inner
carry. Let `F_k` be the set of words reachable from the projection of
`orbit 196 100` (a 47-digit number) by repeatedly applying `forwardPrefix` with
both carry choices. Then every later projection of the 196 orbit lies in
`F_k`. The last predecessor of a palindrome reached without a final overflow
has all pair sums at most 9 and they are the palindrome's digits, so its
projection is the palindrome's leading `k` digits. Hence no palindrome in the
196 orbit can begin with a `k`-digit word outside `F_k` (if a final overflow
into it is impossible), at any time; times up to 100 are covered by the
existing kernel check.

## Exploration (untrusted)

`exploration/validate2.py` checks the argument on eight seeds that do reach
palindromes (89, 187, 10911, 1186060307891929990, ...): in every case the
actual last predecessor's projection lies in the forward closure of an
earlier projection. Closure sizes are nearly identical for these seeds, which
suggests one dominant forward attractor of the abstraction rather than a
196-specific set; the Lean statement is proved for 196 only.
