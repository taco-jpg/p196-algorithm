## 需要保持的解释边界

1. `State` 的字段类型允许不可达状态。`Transition`、`Terminal` 定义在全部 `State` 上，其定义域比 Python 枚举出的 46 个可达状态大。任意状态上的逐点等价不得替代“初态可达子图上等价”；最终 `Tables` 模块必须负责可达闭包及字面枚举对应。
2. `emit` 使用 `Int.toNat`。在非法的溢出且负延迟状态上，它与 Python 整数加法不同。合法初态及 `nextState` 保证接受路径不会出现此情况。最终解释必须限于可达/接受路径。
3. `Accepts L q p` 仅读 `q` 的 folded prefix 和可选中心；它不会单独要求 `q` 右半边对称。连接基础 `nextColumns` 的定理必须带 `Admissible L q` 或等价的完整对称字条件。
4. `q`、十进制数字函数、路径函数在有限有效前缀以外允许任意取值。正式唯一性应为 `∀ i ≤ L/2, p i = actualState L q i` 或 `finitePath` 相等；全函数唯一性为假。
5. 对实际整数的结论必须适用于每个满足 `Canonical n d L` 且其列和等于输入字的实现，不能只证明某个特制 `realizingDigit` 实现。基础 `representation_next` 为这一强形式提供支持。
6. 一般长度定理不能由任何有限 Python 测试替代。此任务不提供不变量，不证明任何种子的无限回文规避，也不解决 196 猜想。
