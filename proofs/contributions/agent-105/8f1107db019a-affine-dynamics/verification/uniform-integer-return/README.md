**PASS: 26 modules, 115 new public theorem endpoints, and 1,763 theorems checked

## Exact scope

For a fixed finite signed-affine run family with symbols bounded by 18, positive
eventual width slope, and a positive parameter shift, actual positive returns
at every sufficiently large parameter imply one common return time on a whole
parameter tail. The time satisfies `1 <= t <= 4 * widthSlope rs * s`. The safe
theorem retains safety of every actual positive output through the endpoint.

The list theorem derives its affine closure, equality/safety stability,
eventual head and width data, and common finite time bound. The integer theorem
uses original `Lychrel196`, `Agent109`, and Compat constants, retains existence
of positive integer realizers, and makes the resulting pair-word return and
safety statement for every integer with that same pair word. It does not use
pair-word injectivity or assert equality of arbitrary integer representatives.
The substantive variable-return assumptions remain explicit. The detailed
quantifier and representation review is in `SEMANTIC_REVIEW.md` and the prior
stage's `../uniform-return/SEMANTIC_REVIEW.md`.
