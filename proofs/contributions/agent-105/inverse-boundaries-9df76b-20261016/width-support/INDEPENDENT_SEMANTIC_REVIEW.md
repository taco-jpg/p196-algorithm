六条公开声明均使用 `Lychrel196.step` 的普通自然数语义，源表示由 `DecimalDigits.Canonical` 保证正性、真实宽度、有效数位和非零首位。它们没有把抽象 pair-word 转移当作数值加法。

## 正回文目标分类：两方向与宽度边界均完整

主等价定理量化的是所有正自然数前驱：

```lean
(∃ n, 0 < n ∧ step n = P) ↔
  W % 2 = 0 ∨ e (W / 2) % 2 = 0
```

它的前提包括 `Canonical P e W` 和 `Palindrome P`。因此分类对象是正十进制回文目标，不能省略回文前提后推广为任意正输出。

充分性使用既有 `realizingDigit` 明确构造同宽规范整数。目标数位在 0 到 9 内，中心奇偶条件使对称列和能够实现；所有真实进位，包括最后一个进位，都为零。构造实际满足 `step n = P`，不是只构造一个没有数值实现的系数词。

必要性从任意正前驱取得规范表示，完整分为不溢出与溢出两种情况，并通过规范宽度及数位唯一性回到指定目标表示。奇宽不溢出的中间列是同一个源数字的两倍，故中心输出位为偶数。

奇宽目标的溢出分支来自偶宽源。代码使用源的两个相邻镜像中列相等，以及回文溢出的列和值只能为 0 或 11，推出目标中心位只能是 0 或 2。这里没有错误地假设偶宽源存在单独中心列，也没有将目标与源的中心索引混淆。

主分类包括 `W = 1`，并按中心偶数条件覆盖一位数目标。`Canonical` 排除了宽度零、全零表示及以零作首位的伪宽度。
