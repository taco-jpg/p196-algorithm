This source-metadata helper will generate the exact scoped registry from the
actual `Agent1PeriodicGuardedPath` root. It executes no Lean, changes no
mathematical source or global accepted registry, and performs no Git mutation.
Final freeze requires the author's checked source and full-module audit.

`9d6dc9caa3e77b9036b348ac6d77c3f49553ba30`; its exact Git blob is
`a36f0e57810090f2ec712f215e210cebebed52e0`. `claim.json` and
`claim-read.json` preserve the actual bytes, command, hash and successful exit.

`946c69edf3d2e6a87f5516db1fd0091eae29e663`; no future new-source commit is

blob IDs match those pins. The final preflight independently parses the new

The source-only ownership report is preserved unchanged under `support/`,
SHA-256 `e1b6c103145122ba65b9dddd448546c5988dc62b1fc590f3c6380ec8c3c80a8a`.
The original periodic METHOD section 4 already states the finite large-copy
guard principle. This package's narrow target formalizes that principle and
connects an entire supplied exact quotient path to the existing ordinary
numeric representation theorem. It does not reprove a generic numeric bridge
or claim affirmative interface search.

For a fixed finite path and length `N`, the planned initial copy count is
`2*N+3`; the same chosen positive seed must represent all times `i ≤ N`.
That seed is permitted to depend on the path and on `N`. Neither this registry
nor the target licenses an interchange to one seed for every horizon, an
infinite safe orbit, a cycle-existence claim, or realization of an arbitrary
path in a necessary-condition graph.

From `/workspace/p196-agent1-guarded-path-20261017`, once the actual source
exists:

```

```

Each run uses a new directory and preserves its exact script, source,
registry and report. The default registry is provisional. A later run with
`--author-checked` requires an actual frozen-author confirmation and matching
strict compile/full-module audit receipt hashes; it still labels parent and
independent fresh verification as pending. The whole source closure is scanned
for prohibited proof shortcuts after masking nested comments and strings.
This limited source check is not a kernel run or a transitive axiom audit.
