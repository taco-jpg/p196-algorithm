## 1. 普通整数和目标定义

- `Lychrel196.step n = n + reverse10 n`，`orbit n 0 = n`，`orbit n (t+1) = step (orbit n t)`。
- `Palindrome n` 是普通十进制数值反转等于原数。数值反转允许原数末尾为零，反转后舍去的高端零对整数值无影响。迭代在回文后继续，定理不要求终点是首次回文。
- `Canonical P e W` 含精确正宽度、各位 ≤9、最高位为正及实际位值等于 P。位置 i 从个位端递增。
- `Starts3 6 2 0 P` 读取 `e(W−1)=6`、`e(W−2)=2`、`e(W−3)=0`，且 W≥3；它的方向确实是最高位开始的 620。
- `PalStarts3 6 2 0 P` 额外明确合取 `Palindrome P`，并未把普通 620 前缀误当成回文。
- 最终祖先定理必须保留 `0 < A`。现有 `ancestry_bound_of_R` 正确保留该条件，用它调用 canonical existence，并借助实际迭代保持可实现性。

## 2. 最后一步与初始集合：为什么是 11+1

`PalindromeBridge.no_overflow_of_target_leading_gt_one` 不假设源目标同宽：若末次相加溢出，目标新最高位必是 1，与目标最高位 6 矛盾。`canonical_unique` 通过已证的真实 decimalLength 唯一性确定宽度，而不是用数位数组的声明长度替代它。

`canonical_last_step` 随后使用回文性和不溢出条件证明所有实际进位为零，源的完整对称列和逐列等于目标的数字；它没有将“无溢出”误当成一般“没有进位”。目标回文的对称性再把高端 620 转成源对和字低端的 `q 0=6,q 1=2,q 2=0`。

`initialWordsK` 从长度 3..7 的十进制尾词生成集合。长度恰为 7 时保留任意四个数字；长度小于 7 时要求完整对称和奇宽中心为偶数。`target_project_mem_initialWordsK` 对 min(L,7) 证明覆盖；`canonical_last_step_initialK` 将真正末次前驱接到它。

独立重算得到：

- 10,000 个长度 7 的 `(6,2,0,d3,d4,d5,d6)`。
- 长度 5 的 `(6,2,0,2,6)`，秩为 1。
- 长度 6 的 `(6,2,0,0,2,6)`，秩为 5。
- 长度 3、4 无满足该前缀的对称短字。

合计 10,002 个初始状态，均已在树的数据集中，最大秩为 11。奇宽中心偶数条件不能删；短初始字不能用所有任意短前缀替代。

对于 `orbit A (t+1)=P`，rank theorem 应用于 `orbit A t` 的对和字，得到 t≤11，最后才推出 t+1≤12。`t=0` 的祖先情况由非负自然数直接处理；`t=1` 应用于前驱时间 0，不会发生负时间或额外减 1。

## 3. 所有宽度的真实投影

`projectK k q L = wordPrefix q (min L k)`：短字保留全部精确长度，长字仅保留 k 列。

`ActualPrefix.actual_forwardPrefix` 中的高端未观测进位是实际的 `carry q (L-k)`；低端为实际初始零进位。证明只需 k≤L，**不要求两个边界区间互不重叠**。因此 L=7、8..13 以及 ≥14 均覆盖。L=7 时真实内侧进位为 `carry q 0=0`；允许另一个可能进位只会增添抽象候选。

`actual_noOverflow` 和 `actual_overflowTail` 从相同完整真实进位链推导每一列关系。溢出分支将高端数字向一列错开，并在尾部保留合法的未观测二值进位存在条件。`actual_longCompatible` 明确保留来源外侧和正性；`actual_mem_prefixPredecessors` 把这个真实关系放进完整逆枚举。

`actual_iterPairs_rank_R` 对每个实际前向时间步倒推一次秩：

1. 来源 L<7 时，后继宽度至多 L+1≤7，故 `projectK_short` 与 `nextWord_wordOf` 给出精确完整短字后继。
2. 来源 L≥7 时，宽度不减少，来源及后继都使用长度 7 前缀，通过完整长逆枚举下降。

因此唯一可能的短到长交界 L=6→7 已由短分支包括。当前 620 闭包恰好没有指向其排名状态的 6→7 短边；这只是独立枚举结果，**证明没有假设这种边不存在**。

## 4. 短字穷尽和六条准确短边

`symWords n` 用 ceil(n/2) 个 0..18 系数镜像生成完整字，过滤外侧正性与奇宽偶中心。`wordOf_mem_symWords` 是对所有 Admissible 的覆盖定理，不依赖测试。n=0 生成的空词外侧默认为 0，被过滤；真实正数从不会需要空状态。

独立程序对 n=1..6 全部 10,467 个 admissible 对和字，以整数 `sum q_i*10^i` 的普通十进制展开计算下一对和字，得到以下所有指向排名状态的短边：

`ShortClosed` 的方向正确：若完整后继在排名树，完整来源也必须在树且秩严格更小。`shortOKC` 在后继未排名时返回 true 合理，因为 rank induction 只从已排名终点向后追踪；在后继排名时调用 `belowC`，来源缺失会返回 false。

## 5. CodeCert 的证据合同

已通读 `Agent124CodeCert` 全部 soundness 定理和执行定义，并核对 `Agent124FastPred`、`FastInverse`、`PrefixInverse` 的完整性链。

- `wordCode` 从标记 1 开始按基数 19 编码；`decode_wordCode` 只在所有系数 <19、长度≤32 下使用。实际长度 7 前缀由 `wordPrefix_lt19` 保证，两项前提均已接入 `rowsClosed_of_all`。
- `lookupC_all` 不信任树排序。一次成功查找必对应某个节点的 key/rank；所有实际能返回的节点都受 `All` 行合同约束。错误排序会使需要的 key 丢失，不能跳过所需初始或前驱检查。

- `chkNo`/`chkNoTop` 分别覆盖四个下一进位组合，首列额外保留外侧正性；`chkNo_sound` 和 `chkNoTop_sound` 将布尔检查转换成所有 noPred2 前驱均存在且秩更小。
