# Agent #217 — Uniformity condition for extracting one fixed finite seed\n\n## Result\n\nThe exact bridge from finite-horizon trajectories to one all-time seed is not\n\n`∀ R, ∃ n, ∀ t ≤ R, Safe(n,t)`.\n\nThe required statement is\n\n`∃ n, ∀ R, ∀ t ≤ R, Safe(n,t)`.\n\nThat is equivalent to\n\n`∃ n, ∀ t, Safe(n,t)`\n\nby the elementary choice R=t. The Lean module `proofs/contributions/agent-217/uniformity/UniformityCondition.lean` formalizes this equivalence.\n\n## Why the finite-horizon statement is insufficient\n\nThe finite-horizon statement permits the witness seed to depend on R:\n\n`∀ R ∃ n_R ∀ t≤R, Safe(n_R,t)`.\n\nThe all-time conclusion requires one seed chosen before the time quantifier:\n\n`∃ n ∀ t, Safe(n,t)`.\n\nAgent122.Countermodel.finite_prefix_extraction_fails is already a kernel-checked formal counterexample to this quantifier interchange for a fixed artificial update map. Its scope is deliberately limited: it is not an actual reverse-and-add counterexample to the Lychrel problem. It nevertheless proves that the logical extraction cannot be justified from finite-prefix existence alone.\n\n## A concrete sufficient condition relevant to the actual problem\n\nFix a decimal width L and let S_L be the finite set of positive L-digit integers. For each horizon R define\n\n`S_{L,R} = { n in S_L : ∀ t≤R, Safe(n,t) }`.\n\nThese sets are nested:\n\n`S_{L,R+1} ⊆ S_{L,R}`.\n\nTherefore, if one proves the genuinely uniform-width hypothesis\n\n`∀ R, S_{L,R} is nonempty`\n\nfor one fixed L, finiteness of S_L forces the intersection over all R to be nonempty. Any n in that intersection is a single finite decimal seed safe for every time.\n\nEquivalently, a positive lower bound on the surviving fraction inside one fixed finite seed ensemble, valid for every R, is enough. The crucial order is fix L first, then quantify over every horizon R. Allowing L (and hence the candidate seed set) to grow with R does not supply the compactness step.\n\n## Consequence for current P196 research\n\nThe repository's finite-horizon and density results therefore need one of the following to close the extraction gap:\n\n1. A fixed finite seed ensemble with nonempty safe set at every horizon.\n2. A stronger uniform survivor-fraction lower bound on one fixed finite ensemble for all horizons.\n3. Another explicit compactness/recurrence theorem that supplies the same fixed-seed conclusion.\n\nA horizon-dependent seed width, density-one statement for each separately growing width, or `∀R ∃n_R` construction is not enough.\n\nThis is a structural prerequisite, not a proof of decimal Lychrel existence or a proof about 196.\n
