# Tools written on 2026-11-11 (base-10 Lychrel hunt)

All programs are single files, no dependencies beyond a C++17 compiler and Python 3.
Build: `g++ -O2 -o NAME NAME.cpp`.

| file | what it does | usage |
|---|---|---|
| `census.cpp` | Enumerates every overflow clock of time period T that the top column can realise (not all necklaces), then builds the rooted column chain for each one. Prints clocks that carry an infinite chain or hit the node cap. | `./census T [cap]` |
| `bigclos2.cpp` | Lean complete rooted closure for one clock (32 to 84 bytes per column history, 17 million histories in about 4 minutes). Reports liveness, cyclic components, and the centre-free fold test (every column periodic from the moment the fold creates it). Third argument is the base (default 10). | `./bigclos2 CLOCK CAP [BASE]` |
| `foldmachine.cpp` | Driven fold machine. Takes the periodic histories of all live columns (from `dump_live.py`), puts the real fold behind each one at every phase, tries every seed interior up to a given number of digits, and reports how long the returned carry stays the one the column needs. | `python3 dump_live.py CLOCK out.txt [BASE]` then `./foldmachine out.txt MAXSEEDLEN MAXSTEPS [BASE]` |
| `kernel.cpp` | Robust-exterior safety game on the pair sums of the outer k columns (19^k states). A nonempty safe set would prove a Lychrel number from its outer digits alone. | `./kernel K` |
| `dive40.cpp` | Samples chains for clock (01)^k whose columns have a temporal period not dividing 8. | `./dive40 K SECONDS SEED` |
| `collide.py`, `dual.py`, `dual2.py` | Complement-mirror (nine-piston) family built on the p11 and p12 exteriors and its collision with the fold. | `python3 collide.py` |
| `selfmirror.py`, `cuts.py` | Python versions of the fold test and of the naive-cut experiment. | `python3 cuts.py CLOCK STEPS` |

Controls (positive, so the finders do find certificates where they exist):
- `./bigclos2 0001100011 3000000 9` reports `***CENTRE-FREE CANDIDATE***` (the base-9 lattice certificate).
- `./bigclos2 0000101001 3000000 13` reports `***CENTRE-FREE CANDIDATE***` (base 13).
- `./foldmachine` on base 2, clock 0101, finds seeds of 2 digits that survive every step tested; on base 9 it survives with an empty seed.

Files in `hunt/`:
- `T13.log` ... `T42.log`: census output per period (one SUMMARY line each).
- `capped.txt`: clocks whose closure exceeded 60,000 histories in the census.
- `resolved_all.txt`: capped clocks whose closure was later completed.
- `still_open.txt`: capped clocks not yet completed. To finish them on a machine with more memory:
  `while read c; do ./bigclos2 $c 400000000; done < hunt/still_open.txt`
